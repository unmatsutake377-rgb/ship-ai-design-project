## Ursell 반원 heave 구현 — 주파수 의존 2D 계수 개통 (시험 339)

원전 (식 7.55~7.82) 그대로: 멀티폴 급수 ψA'_2m + 방사파 ψB (특이
적분 H·G는 scipy quad, x=0은 진동 weight 적분) → 경계조건
collocation 최소자승 → P2m·Q2m·진폭비·위상 → 압력 하중 적분 →
M33'(ω)·N33'(ω).

**검증 4/4 — 전부 명중**:
- **에너지 항등식** N33' = ρg²(ηa/ya)²/ω³: 비 1.000 (0.1% 이내,
  ξr 0.1~5) — 급수·연립·적분 전체의 자기 일관 (가장 강한 심판)
- 고주파 극한 → ρπR²/2 (1단계 Lewis 해석값과 접점, ξr=10에서 95%)
- **문헌 곡선 재현**: 부가질량 저주파 상승(1.41·ref @ ξr 0.1) →
  골짜기 0.60·ref @ ξr≈1 → 회복 — Ursell 1949의 유명한 dip 정확
- 감쇠 전 구간 양수, 피크 ξr~0.25

내항성 1단계 잔여 = Tasai (Lewis 사상으로 이 계산을 일반 단면에
확장 — 원전 p274~ 인덱스 확보됨). 반원 코어가 검증됐으니 확장은
사상 변수 치환이 본체.

## Lewis 식 7.95 승급 + Frank 방법 채택·재료 완비 (시험 339)

  컨텍스트 신선한 다음 회차 첫 수로.

## Frank close-fit 개통 — 임의 단면 2D 계수 (시험 341, 08-09 회차)

원전 7.113~7.142 구현: 진동 점원 Green 함수 (PV 특이적분 대칭
정칙화) + 전체 윤곽 상수 소스 세그먼트 + 복소 연립 → M33'(ω)·
N33'(ω). **격리 사다리가 사고 2건 검거**:

1. **Green 함수 Re 구조 사고**: 원전 7.123의 G = Re{A} − i·Re{B}
   (실부 조합)를 전체 복소로 구현 → 자유표면 조건 위반. 격리 검사
   ②(자유표면 잔차)가 병소 지목 — y=0에서 ln쌍은 실부만 소멸
   (켤레 쌍)이라 Re 구조가 물리의 본질
2. **힘 방향 사고**: 크기 1~2% 일치·부호 전체 반전 → 압력이 몸을
   안쪽으로 미는 F = −∮p·n̂ ds 누락 (자기항 반전 시도는 오답으로
   판명 — 연립 구조가 깨지는 걸 실측으로 확인 후 복원)

**최종 검증**: 반원 Ursell 이중검증 — a33 2~4%·b33 저중주파 1%
(32 seg), 세그먼트 수렴 96에서 전 대역 1.5% (고주파는 파장↓ →
해상도↑ 필요, 물리 정합). 임의 단면 능력: 직사각형 성질 통과.

**1단계 완결**: Lewis 사상·메쉬 추출·Ursell 표준기·Frank 임의
단면 — 2D 계수 사슬 전부 개통. 다음 = 2단계 스트립 적분 →
heave·pitch RAO (Wigley 문헌 앵커).

## 스트립 이론 RAO 개통 — 내항성 2단계 1차 (시험 344)

**seakeeping/strip.py**: 원전 8.3 (Ordinary Strip Theory, 식
8.21~8.46) — 스테이션 Frank 2D 계수 → 길이 적분 (heave·pitch 연성
계수 9종 + V 전진속도 항 수치 조립) → FK 유효진폭 C3 기진력 →
2×2 복소 운동방정식 → RAO(ω). Lewis 사상 곡선을 Frank 윤곽으로
재사용 (물리=형상 동일 소스).

**해석 극한 앵커 3/3 — 교과서 곡선 재현**:
- 장파 (λ/L=8): heave 0.997·pitch 1.041 — "배가 파면을 그대로
  탄다" 극한 (해석 확정값 1)
- 단파 (λ/L=0.5): 0.05·0.02 — 상쇄 소멸
- 중간: heave 단조 전이 + pitch 피크 1.37 @ λ/L 1.2 (문헌 대역)

사고 1: 홀수 가우스 절점이 자기 세그먼트 중점과 겹쳐 0나눗셈 —
짝수 강제로 수리.

**파이프라인 최초로 "배 전체가 파도에 응답"**. 잔여: Wigley 문헌
실측 대조 (Journée 1992 데이터 확보 시 — 백로그), 3단계
roll·불규칙파 성적, 4단계 5번째 게이트.

## 불규칙파 성적표 — 내항성 3단계 (시험 349)

**seakeeping/waves.py**: ITTC/ISSC 스펙트럼 + roll 공진 모델 +
유의 응답 통합 성적표.

앵커 5/5:
- **스펙트럼 항등식 m0 = Hs²/16** (유의파고 정의 정합 — 공식
  계수의 자기 심판, 2% 이내)
- **roll 공진 해석값 RAO(ωn) = 1/(2κ)** 정확 + 저주파 파면 추종 극한
- 선형계 성질 (응답 ∝ 파고, 1e-6 정밀)
- 유의 roll 자릿수 (100 m 화물선·Hs 3 m: 한 자릿수 도 — 상선 통상)
- 관통: seakeeping_report — 배+해상(Hs·Tz) → 유의 heave[m]·
  pitch[deg]·roll[deg] + 고유주기

정직 표기: roll 감쇠비 κ 0.06 C급 (Ikeda 정식 후속), roll = 횡파
보수 (선수파 항해 시 실제는 이보다 작음), heave·pitch V=0.

**"이 배는 이 파도에서 얼마나 흔들리나"에 숫자로 답하는 능력 완성.**
잔여: 4단계 — 5번째 게이트 (용도별 기준 합불) + 파이프라인 배선.

## 5번째 게이트 배선 — 내항성 캠페인 완주 (시험 350)
