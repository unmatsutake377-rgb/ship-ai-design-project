## Ursell 반원 heave 구현 — 주파수 의존 2D 계수 개통 (시험 339)

원전 (식 7.55~7.82) 그대로: 멀티폴 급수 ψA'_2m + 방사파 ψB (특이
적분 H·G는 scipy quad, x=0은 진동 weight 적분) → 경계조건
collocation 최소자승 → P2m·Q2m·진폭비·위상 → 압력 하중 적분 →
M33'(ω)·N33'(ω).

**검증 4/4 — 전부 명중**:
- **에너지 항등식** N33' = ρg²(ηa/ya)²/ω³: 비 1.000 (0.1% 이내,
  ξr 0.1~5) — 급수·연립·적분 전체의 자기 일관 (가장 강한 심판)
- 고주파 극한 → ρπR²/2 (1단계 Lewis 해석값과 접점, ξr=10에서 95%)
- **문헌 곡선 재현**: 부가질량 저주파 상승(1.41·ref @ ξr 0.1) →
  골짜기 0.60·ref @ ξr≈1 → 회복 — Ursell 1949의 유명한 dip 정확
- 감쇠 전 구간 양수, 피크 ξr~0.25

내항성 1단계 잔여 = Tasai (Lewis 사상으로 이 계산을 일반 단면에
확장 — 원전 p274~ 인덱스 확보됨). 반원 코어가 검증됐으니 확장은
사상 변수 치환이 본체.
