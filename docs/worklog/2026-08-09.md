## 1단계 성적표 — 하중 곡선 (완주)

### 원전 확보

- IACS UR S11 Rev.9 (2019) — turkloydu.org 선급 미러 (iacs.org.uk
  목록은 JS 렌더라 직링크 불가). `references/IACS_UR_S11.pdf`
- **계획 예상 상수와 원전 완전 일치**: 호깅 +190·M·C·L²·B·Cb·10⁻³,
  새깅 −110·M·C·L²·B·(Cb+0.7)·10⁻³ [kN·m], C 구간식 3개, Cb 하한
  0.6 클램프, 적용 강선 L≥90m. 허용 응력 σ=175/k N/mm²도 확인
  (3단계 재료)

### 검증 앵커 성적

| 앵커 | 결과 |
|---|---|
| 바지선 중앙 몰림 \|M_mid\| = WL/16 (손계산) | 오차 < 2%, 새깅 부호 정확 |
| 균일 바지선 M ≈ 0 전역 (항등식) | < 1% (WL/16 스케일) |

### 3중 교차검증 — 100m 화물선 (5000t 화물, 표준파 a=L/40)

| 방법 | M_wave (미드십) | 비 (IACS=1) |
|---|---|---|
| IACS UR S11 (극치 통계 내장) | 1.79×10⁸ N·m | 1.00 |
| 표준파 준정적 (정수압 쐐기) | 1.19×10⁸ N·m | 0.67 |
| 스트립 FK 구속 (Smith 감쇠) | 1.02×10⁸ N·m | 0.57 |

서열이 물리 그대로: IACS(설계 극치) > 준정적(감쇠 없는 상한) >
스트립(깊이 감쇠 e^{−kT} 반영). **세 독립 방법이 같은 자릿수 합의.**

### 검거·교훈

1. **상자 메쉬 희소점 함정**: `station_geometry`(점 판독)가 상자
   원시 꼭짓점에서 21개 중 5개 스테이션만 통과 — 배가 선미 19m
   조각으로 잘려 굽힘 0 오판. 시험 메쉬 세분화(subdivide)로 해결.
   신설 `station_area`는 처음부터 스캔라인(변 교차)이라 면역.
2. **λ=L에서 준정적 vs FK 20% 일치 기대는 과욕**: 비 0.65는 오차가
   아니라 Smith 효과(파 압력 깊이 감쇠) — 시험을 대역 판정(0.5~1.0)
   으로 정정. "준정적 = 보수적 상한"이 정확한 물리 서술.
3. 자유 운동 해 힘 폐합이 기계 정밀도로 0 — 하중 적분과 운동방정식이
   같은 가중치를 쓰면 해석적 항등식이 수치에서도 그대로 성립.
