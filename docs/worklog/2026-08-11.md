# Molland 쌍동 간섭 원전 사냥 — 위치 확정·접근 대기 (정직 미승급)

Fable 부재로 Fable 권장분(Jensen·advance) 스킵, Opus/Sonnet 몫
순차 진행 첫 건. reference-hunter(sonnet) 첫 실전 — 쌍동 저항
간섭계수 공개본 사냥.

- **헌터 성과**: 정확한 원전 계보 특정 — Insel & Molland (1992,
  Trans RINA 134, σ/τ 간섭인자 정의) + Molland-Wellicome-Couser
  (1994, Southampton Ship Science Report 71·72, s/L 0.2~0.5·Fn
  0.1~1.0 계통 실험). 무료 공개본 eprints.soton.ac.uk/46442·/46441
- **막힌 지점**: Southampton ePrints가 **Anubis 봇 챌린지(PoW)**로
  자동 도구(WebFetch·curl) 차단. 메인이 인앱 브라우저로 재시도 →
