## interFoam 자유수면 실증 (Task 8)

**1차 실행 — 침수 버그 발견** (교훈 가치 높음):
- 결과 279.3 N (경험식 28.9 N의 약 10배) + 미수렴 ⚠. 겉보기엔 "CFD가 원래 다르네"로 넘어갈 수 있는 수치
- **힘 시계열 분석으로 진단**: t 0→19.7s에 걸쳐 저항이 134→279 N으로 **단조 증가** — 초기 과도현상이면 감소해야 하므로 모순. 점성 성분 36 N = 단상(5.3 N)의 7배 = 젖은 면적 폭증 신호
- 진범: 입구 경계 alpha=1이 **수면 위 공기층까지 물을 주입** → 수위 계속 상승 → 배가 갑판까지 침수. (템플릿 작성 때 "의심 1순위" 주석으로 박아둔 바로 그 지점 — 위험 예고가 적중)
- 수리: blockMesh를 수면(z=0)에서 2단 적층 — inletWater(alpha=1) / inletAir(inletOutlet 0) 분리. 시험으로 고정 (`inletWater` 존재 단정)
- 방법론 교훈 재확인: "그럴듯한 숫자도 시계열을 뜯어보면 거짓말을 실토한다" — Phase B 격리 실험과 같은 정신

**2차 실행 (수리 후) — 성공**: 시계열이 정직해짐 — 초기 과도 68.6 N이
가라앉아 t≈7s부터 **15~16 N에 평탄 정착** (창 std 0.9 N). 1차의 "단조
증가"와 정반대 = 수리 입증. 수렴 플래그는 '아니오'(CoV 5.5% > 기준 2%)
— 파도 진동 탓, 준수렴으로 기록.

**3중 대조표** (Wigley 데모선 L=1.97 m, 1.5 m/s, Fn 0.341):

| 저항 성분 | 경험식 | CFD (거친 격자) | 비고 |
|---|---|---|---|
| 마찰/점성 | ITTC-57: 7.6 N | 단상 5.3 / 자유수면 3.8 N | 자릿수 ✓ (비 0.5~0.7 — 거친 격자 과소예측 경향) |
| 조파/압력 | Michell: 21.3 N | inter 압력 12.6 N, 그중 조파 추정(inter−이중모형) ≈ 4.2 N | 아래 발견 참조 |
| 전체 | 28.9 N | 16.4 N | 자릿수 ✓ (비 0.57) |

**물리 발견 — Michell의 가정 위반이 숫자로 보였다**: 문헌 Cw 밴드
[4e-4, 4e-3]는 **날씬한 표준 Wigley (L/B=10)** 기준. 우리 데모선은
L/B=2.0의 통통한 배 — Michell의 "얇은 배" 가정을 정면 위반. 환산 결과
Michell Cw=1.2e-2 (밴드 밖, 과대), CFD 조파 추정 Cw=2.4e-3 (밴드 안).
즉 통통한 배에서 Michell이 ~5배 과대예측하는 그림 — 얇은 배 가정의
한계가 CFD 훅으로 처음 정량 관측됨. (단 거친 격자는 파도를 감쇠시켜
과소예측 방향 — 진짜 값은 둘 사이. 격자 수렴 연구가 후속 과제인 이유)

**성공 기준 판정** (스펙 §4): 배관 관통(생성→실행→파싱→CSV 2행) ✓ +
단상 마찰 ITTC 자릿수 ✓ — **CFD 훅 완결**. interFoam 정확도는 성공
조건 아님 (기록만).

## 능동 학습 1회전 (같은 날 후속 — 스펙·계획 별도 문서)

**구성** (오너 결정: 보정 계수 / L/B 스팬 3척 / 접근 A):
L/B 4·7·10 Wigley 3척 (Fn=0.341 고정, 변인 통제) × 단상·자유수면 6런
→ 라벨 8행 → ratio_w(B/L)=1+b·(B/L) 적합 → 파레토 24척 재평가.
새 코드: samples.py(표본) + calibration.py(적합·재평가), 시험 189→199.

**결과 — 직선 가설 기각 (여유 2점이 제 몫을 함)**:

| B/L | 0.10 (L/B10) | 0.143 (L/B7) | 0.25 (L/B4) | 0.50 (L/B2) |
|---|---|---|---|---|
| 관측 ratio | **0.06** | 0.23 | 0.42 | 0.20 |
| 적합 (b=−2.19) | 0.78 | 0.69 | 0.45 | 0.05 |

잔차 거대 + 비단조 — 매개변수 1개에 점 4개를 쓴 이유("점이 남아야
가설을 검증한다")가 실전에서 작동한 첫 사례. **b=−2.19 채택 안 함.**

**원인 규명**: 날씬한 배일수록 파도 진폭↓ → 거친 격자가 작은 파도를
수치적으로 잡아먹음 (L/B=10 조파 추정 0.1 N = Michell의 6%). 관측
비율 = Michell 오차 × **격자 감쇠**의 곱 — 날씬한 쪽은 격자 감쇠가
지배해 배우려던 물리가 묻힘. 예상("표준 Wigley에서 ratio≈1")과 정반대
데이터가 나온 것 자체가 격자 문제의 결정적 증거.

**능동 학습이 실제로 가르쳐준 것**: 다음 표본은 L/B 추가가 아니라
**격자 수렴 연구** (파장당 셀 수 확보 후 재시도). "다음 실험을 어디에
하나"를 데이터가 알려줌 — 이것이 능동 학습 루프의 본질이고, 1회전의
산출물은 계수가 아니라 이 방향 전환이다.

**기계 검증**: 사이클 배관(표본→6런 병렬→라벨→적합→재평가→그림)은
전 구간 관통 ✓ — 격자만 좋아지면 같은 명령 한 줄로 재회전 가능.
파레토 재평가(전선 24→16척)는 외삽 시연으로만 기록, 미채택.

## MaxBox 탑재 공간 제약 (#27 — 7/28 외부 AI 창작에서 구제된 항목의 완결)

**오너 결정**: "용도는 사용자의 마음, 우리는 실제로 구현되는 배인지
판단" → **제약 + 여유 표기 (B+C안)**, 목적함수(4목적) 기각. 부피
입력은 밀도 프리셋 + `--payload-volume` 직접 입력 우선.

**메운 구멍**: 기존엔 짐을 무게로만 검사 (아르키메데스) — 무게는
실려도 **부피가 안 들어가는** 배를 못 걸렀음.

**구현**: `src/physics/maxbox.py` — 내부 점 격자(contains) → 상자
바닥 높이 z0 스캔 → 반폭 지형도 → 히스토그램 최대 직사각형(고전
알고리즘, 손계산 정답지) → 최대 부피 상자. 바지선 해석 정답 + Wigley
경향 pytest. 파이프라인 4번째 검사 `payload_space` (정역학 모듈은 물에
뜨는 문제만 — 책임 분리로 run_pipeline 층에서 합성). 시험 199→206.

**검사가 첫 출근에 일을 함**: 초안 밀도 400 균일에서 데모선(2m,
100 kg)이 공간 부족 판정 — 조사장비는 밀도 높은 부류(배터리 ~2000,
전자 ~500-1000)라 적부율 대역(333~667 kg/m³) 근거로 survey/patrol
600·workboat 400 재설정. 임의 초안을 검사 결과가 교정한 사례.
데모 최종: MaxBox 1.24×0.57×0.30 m = 0.216 m³ vs 짐 0.167 m³ →
여유 +29% 통과 / 50 m³ 요청 → 공간 부족 정직 탈락.

**관례 이탈 기록**: 오너 핫스팟 데이터 절약을 위해 별도 계획서 생략
(스펙이 알고리즘 수준까지 상세해 대체) — 1회성 예외.
