# 2026-08-10 — 대형 화물창 용적 게이트: 전선의 "미검" 각주를 지우다

## 유래·결정

NSGA 캠페인의 정직 각주 ("날씬 전선이 8,000t를 실을 수 있는지
미검") 해소 — 오너 직접 지시. 8중 게이트의 space 축이 대형 분기에
비어 있던 구멍을 메움 (게이트 수 불변). 스펙
`2026-08-09-cargo-capacity-design.md`.

## 구현 — src/physics/cargo_capacity.py

화물창 = [전체 내부(z≤depth) − 이중저(B/15, 0.76~2.0m 클램프
SOLAS 계보 C급) − 기관실(선미 15%, 중량 블록 배치 정합) − 연료
탱크(0.9 t/m³)] × 0.90 (grain 공제) — 전부 메쉬 실측 절단
(immersed_volume 계보 재사용). 요구 용적 = payload × 적재계수
1.3 m³/t (실선 1.2~1.5 대역 C급).

**구현 중 정직 정정**: 초안 "소형 밀도 500 재사용" = 과대 요구
오판 (2 m³/t — 소형 장비 환산 전용) → 표준 화물선이 억울한 불합격.
실선 적재계수 1.3으로 정정 (스펙·코드·시험 동시).

**우려는 기우로 판명** — "날씬"은 수선 아래 이야기, 전체 깊이
내부 용적은 3배 여유. 어제의 "미검" 각주를 실측 합격으로 교체 —
진짜 8중 전선의 신뢰성 승격 (남은 각주는 조종 Cb<0.51 대역 밖
하나). 기우였어도 게이트는 남는다 — 다음 NSGA부터 fast 평가에
용적 사망이 포함돼 극단 선형이 아예 못 올라온다.

# 조종 추정 슬렌더 외삽 — 전선의 마지막 각주 해소

## 결정 (자율 관례)

Yoshimura 회귀 하한 Cb 0.51을 **0.40까지 완만 외삽 (C급)** 확장 —
근거: ① Kijima 선형식은 반이론 (0.5πk = 저종횡비 날개 이론 항)
이라 Cb 연속 ② 반대편(풀선형) 외삽이 자기 대조 비 1.02로 관용성
실증. Cb < 0.40은 정직 거절 유지. 부작용 방어: 확장 탓에 2m
USV까지 상선 회귀가 닿는 것을 **L ≥ 20 m 게이트 가드**로 차단
(소형 = 기존 민첩성 지표 담당 — 정직 스킵 2종 체계).

## 심판 — NSGA 전선 3척 조종 실판정
