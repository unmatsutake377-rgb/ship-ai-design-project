# 2026-08-10 — 대형 화물창 용적 게이트: 전선의 "미검" 각주를 지우다

## 유래·결정

NSGA 캠페인의 정직 각주 ("날씬 전선이 8,000t를 실을 수 있는지
미검") 해소 — 오너 직접 지시. 8중 게이트의 space 축이 대형 분기에
비어 있던 구멍을 메움 (게이트 수 불변). 스펙
`2026-08-09-cargo-capacity-design.md`.

## 구현 — src/physics/cargo_capacity.py

화물창 = [전체 내부(z≤depth) − 이중저(B/15, 0.76~2.0m 클램프
SOLAS 계보 C급) − 기관실(선미 15%, 중량 블록 배치 정합) − 연료
탱크(0.9 t/m³)] × 0.90 (grain 공제) — 전부 메쉬 실측 절단
(immersed_volume 계보 재사용). 요구 용적 = payload × 적재계수
1.3 m³/t (실선 1.2~1.5 대역 C급).

**구현 중 정직 정정**: 초안 "소형 밀도 500 재사용" = 과대 요구
오판 (2 m³/t — 소형 장비 환산 전용) → 표준 화물선이 억울한 불합격.
실선 적재계수 1.3으로 정정 (스펙·코드·시험 동시).

## 앵커 성적

| 앵커 | 결과 |
|---|---|
| 상자 손계산 (12,000 − 1,500 − 1,575 − 111)×0.9 | 3% 내 재현 |
| 이중저 클램프 3구간 | 정확 |
| 표준 화물선 (Cb 0.75·8,000t) | 합격 (기존 설계 생존) |
| 적재계수 요구 (8,000t → 10,400 m³) | 정확 |

## 심판의 순간 — NSGA 전선 재판정 (반전)

| 설계 | Cb | hold 실측 | 요구 | 판정 |
|---|---|---|---|---|
| 경제형 (9.9 kn) | 0.44 | 29,771 m³ | 10,400 | **생존 (여유 2.86배)** |
| 경제형2 | 0.44 | 29,536 m³ | 10,400 | 생존 (2.84) |
| 속도형 (14.6 kn) | 0.38 | 35,350 m³ | 10,400 | 생존 (3.40) |

**우려는 기우로 판명** — "날씬"은 수선 아래 이야기, 전체 깊이
내부 용적은 3배 여유. 어제의 "미검" 각주를 실측 합격으로 교체 —
진짜 8중 전선의 신뢰성 승격 (남은 각주는 조종 Cb<0.51 대역 밖
하나). 기우였어도 게이트는 남는다 — 다음 NSGA부터 fast 평가에
용적 사망이 포함돼 극단 선형이 아예 못 올라온다.

## 통합

# 조종 추정 슬렌더 외삽 — 전선의 마지막 각주 해소

## 결정 (자율 관례)

Yoshimura 회귀 하한 Cb 0.51을 **0.40까지 완만 외삽 (C급)** 확장 —
근거: ① Kijima 선형식은 반이론 (0.5πk = 저종횡비 날개 이론 항)
이라 Cb 연속 ② 반대편(풀선형) 외삽이 자기 대조 비 1.02로 관용성
실증. Cb < 0.40은 정직 거절 유지. 부작용 방어: 확장 탓에 2m
USV까지 상선 회귀가 닿는 것을 **L ≥ 20 m 게이트 가드**로 차단
(소형 = 기존 민첩성 지표 담당 — 정직 스킵 2종 체계).

## 심판 — NSGA 전선 3척 조종 실판정

| 설계 | Cb | 조종 판정 | 상세 |
|---|---|---|---|
| 경제형 (9.9 kn) | 0.437 | **합격 (실검)** | D_T 4.46L (≤5)·adv 4.08 (≤4.5)·OSA 4.3° |
| 경제형2 | 0.438 | **합격 (실검)** | D_T 4.49L·adv 4.09·OSA 4.3° |
| 속도형 (14.6 kn) | 0.378 | 스킵 유지 | Cb < 0.40 외삽 한계 밖 — 정직 |

**경제형 = 스킵 0개 완전 검증 8중 합격 확정** (내항·구조·조종·
공간·EEDI 전부 실검) — 어제의 각주 두 개("공간 미검"·"조종 미검")
가 이틀에 걸쳐 전부 실측 판정으로 교체됨. 속도형만 각주 1개
(Cb 0.378 — 외삽 한계 밖, 억지로 늘리지 않는 게 정직).

시험 +1 (슬렌더 대역 검사) — 422 → 423 예상 (회귀 확인 중).

# 쌍동선(카타마란) 캠페인 개시 — 1단계 기하·정역학·저항 완주

## 결정 (자율 관례 — 오너 "1번 진행")

새 캠페인 = 쌍동선 (제품화는 학습 리턴 근거 2회 기각 이력 계승).
폭 통제: 단계 분할 — 1단계 = 관통만, 게이트·전 크기는 후속. 스펙
`2026-08-10-catamaran-design.md`.

## 1단계 성적표 — src/ai/catamaran.py (시험 +4, 첫 시도 4/4)

**심장 발견: 기존 정역학이 쌍동을 자동 지원** —
waterplane_properties가 수선면 폐곡선들을 y=0 기준으로 합산하는
구조라, 데미헐 2개를 ±s/2에 병합만 하면 평행축 정리
I_T = 2×(I_own + A·(s/2)²)가 실측으로 그대로 나옴 (손계산 81.67 m⁴
1% 재현). 새 정역학 코드 0줄.

| 앵커 | 결과 |
|---|---|
| 평행축 손계산 (상자 데미헐×2) | 1% 재현 — 기존 코드 그대로 |
| 간격 단조 s↑ → GM↑ | 방향 정확 (s/B 제곱 성장) |
| BlueBoat급 실선 자릿수 | 흘수 7.2 cm·GM 1.1~2.9 m (s/B 0.5~0.8) |
| 저항 항등식 (데미헐×2) | 정확 (간섭 무시 C급 각주) |

단동 대조: 같은 60 kg 조사선 — 단동 GM 0.28 vs 쌍동 GM 0.46
(1.6배). 날씬한 선체 둘을 벌리는 것만으로 복원이 커지는 쌍동의
존재 이유가 수치로.

백로그 (2단계 이후): 파이프라인 --hull cat 통합·8중 게이트 쌍동
갈래 (내항 roll은 쌍동 별도 물리!)·Molland 간섭 저항 원전·크로스
데크 구조 중량.

## 쌍동 2단계 — 파이프라인 통합 (같은 날 연속)

### 스캔라인 짝수 교차 일반화 (구조 하중의 쌍동 대비)

`station_area`의 max-y 방식은 쌍동 단면(폐곡선 2개)에서 한쪽
데미헐만 읽어 **부력 절반 오독** — 시험이 검거. 각 z의 교차 y들을
정렬해 (y₁,y₂),(y₃,y₄)… 구간 폭 합산으로 일반화 (단동 결과 불변
— 구조·파랑 기존 11 시험 유지). 구조 게이트가 쌍동 종강도까지
자동 대비.

### 파이프라인 `--catamaran`

- 배수량 소형 formula 갈래: 쌍동 메쉬 + 데미헐×2 저항 주입 +
  GM/B 상한 해제 (쌍동 과복원 = 정상) + 계수 메쉬 경로
- 정직 스킵 2종: 내항 (스트립 2D 계수는 단동 단면 Lewis/Frank
  가정 밖 — 쌍동 내항 물리 후속) · space (짐은 크로스데크 탑재 —
  내부 상자 검사 부적용, 데크 모델 백로그)
- 검거: MaxBox가 데미헐 내부만 봐서 쌍동 억울 불합격 → 정직 스킵

### 단동 vs 쌍동 — 같은 임무 (조사 50 kg·1.5 m/s) 첫 대조

| | 단동 | 쌍동 (s/B 0.7) |
|---|---|---|
| GM | 0.16 m | **0.32 m (2배)** |
| 저항 | 43.3 N | **17.7 N (−59%)** |
| 흘수 | 14.3 cm | 25.0 cm |

**날씬 데미헐의 조파 급감 + 평행축 복원 — 쌍동이 조사용 USV에서
이기는 이유가 한 표에.** (간섭 무시 C급 전제 — Molland 원전 확보
시 재검) 시험 427 → 429 (회귀 425+분할 4).

## 쌍동 3단계 — 내항 물리 (같은 날 연속, 캠페인 완주)

### 데미헐 등가 근사 (C급)

선형계 통찰: 몸통 간 유체 상호작용을 무시하면 쌍동의 계수·기진·
질량이 전부 데미헐×2 → **heave·pitch RAO는 "데미헐 + 절반 질량"
문제와 수학적으로 동일** — 기존 스트립 기계 전부 재사용, 새 유체
코드 0줄. roll은 쌍동 실측 GM(평행축)이 공진 주기를 짧게 끌어
자동 반영 (c 계수 단동 IMO 관례 C급 각주).
`seakeeping_gate_catamaran` — 파이프라인 쌍동 내항 스킵 →
**실판정 승격**.

### 첫 실판정 — 정직한 불합격

BlueBoat급 조사 쌍동 (연안 Hs 0.5 m): roll 30.0°·pitch 9.0°·
T_roll 1.2 s (스냅 롤) → **불합격**. 단동 조사선 28.5° 불합격
(내항 캠페인 첫 판정)과 일관 — 2m급 연안 내항 약점은 선형을
가리지 않는다는 검출. 스킵이었으면 몰랐을 판정.

시험 429 → 432 (회귀 428+분할 4). **쌍동 캠페인 3단계 완주** —
기하·정역학·저항·파이프라인·내항까지. 백로그: Molland 간섭 원전·
