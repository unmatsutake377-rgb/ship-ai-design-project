## 전 크기 개방 1단계 — Holtrop 개통 + 벤치마크 + Michell 붕괴 실측 (시험 302)

캠페인 개시 (스펙 2026-08-06-all-size, 오너 A안 승인 — 100m+ 목표,
프로펠러까지 설계, 벤치마크 먼저).

**Holtrop-Mennen 구현** (src/physics/holtrop.py): 형상계수(1+k1)·
조파(구상선수·트랜섬 감쇠 포함)·모형-실선 상관(CA). 부속 공식
손계산 앵커 + KCS 공개 벤치마크 (Kim, Van & Kim 2001 — Ct 3.556e-3
@ Fn 0.26, A급):

- **예측 +13.6% 과대 박제** — Holtrop의 날씬 컨테이너선(Cp 0.66 =
  회귀 DB 하단) 과대 경향 문헌 보고(10~15%)와 일치. 입력 등급 정직
  표기: 기하 A급 / Cm·Cwp·lcb B급 / 구상선수 ABT·hB C급(통상비 개략)
- KVLCC2 실측값 미확보 — 지어내지 않고 백로그 (KCS 1척 개통)
- 실선 24 kn 유효동력 자릿수 검증 (10~30 MW 대역 통과)

**Michell 3자 비교 (230 m Ship-D 상선 문법 배)**: 조파를 Fn 0.16에서
466배, 0.26에서 24.5배 과대 — 얇은 배 가정(B/L≪1)이 B/L 0.23에서
완전 붕괴. **대역 심판 확정: 상선급 = Holtrop, 소형 날씬 = Michell
(Wigley·CFD 검증 계보 유지)**. 크기 스위치가 아니라 모델 유효 대역의
실측 확인 — 2단계(중량·치수·게이트)에서 저항 디스패처에 배선 예정.

## 전 크기 개방 2단계 — 중량·치수·게이트 (시험 308)

**Watson-Gilfillan 강선 경하** (src/physics/large_ship.py): 구조
(K·E^1.36·Cb' 보정)·의장(Co·L·B)·기관(개략 20 kg/kW — 3단계 엔진

대역 명시 (강선 상선 60~350 m) — 소형 회귀와 크기 스위치 없이 공존.

**ICLL Type B 건현표** 대표점 보간 (B급) + **IMO IS Code GM 하한
0.15 m** (A급 규정) — 대형 GM 밴드: 소형 하한(0.04·B)을 대형에
그대로 쓰면 B 30 m에서 GM 1.2 m 요구 = IMO보다 과도 → 규정 절대값
채택, 상한 0.40 유지 (급횡요 원리는 크기 무관).

**cargo 용도 신설** — 소비자 6곳 전수 배선 (스키마 소비자 전수 수색

CB_BY_CATEGORY, Cm 0.98, LCB +2%, 추천 가중 (연비·경량 동급),
화물 밀도 500, 순항 7.0 m/s (~13.6 kn). 손계산 검증: 짐 5,000 t →
L 98.9 m (실선 DWT 5000t급 ~100 m 정합).

나선 관통은 4단계 (추진이 전기 카탈로그에 묶여 있음 — 엔진·프로펠러

## 전 크기 개방 3단계 2차 — Wageningen B 프로펠러 정밀 (시험 318)

오너 결정 "프로펠러까지 설계"의 완성. **환각 방지 관례 준수**:
Kt·Kq 다항 계수(Kt 39항·Kq 47항)를 기억으로 박지 않고 공개 저장소
(mkergoat/bseries — Oosterveld & van Oossanen 1975 수치)에서 확보,
data/wageningen_b_coeffs.csv에 출처 헤더와 함께 보존.

**계수 신뢰 삼각 검증** (B4-70, P/D 1.0): 계류 Kt 0.455 (문헌
0.45~0.50) · 영추력점 J 1.06 (문헌 ~1.05) · 최대 효율 0.68 (문헌
0.65~0.70) — 내 도표 오기억(시험 초안 대역)을 계수가 바로잡음.

**design_propeller**: (P/D, J) 스윕 → 소요 추력 달성점 중 개수 효율
최대 → ηD = η0·ηH·ηR 실산출 (반류 w 0.30·추력감소 t 0.20 개략 C급
— Holtrop 부속식 승급 예정), Keller 캐비테이션 최소 EAR 검사 +
부족 시 1회 재설계. **design_propulsion**: 흘수 제한 직경(0.70T) →
프로펠러 → 엔진 선정 통합 — 개략 ηD 0.60이 실계산으로 대체됨.
100 m급 검증: R 200 kN·7 m/s → D 4.2 m·η0/ηD 정상 대역·캐비테이션
충족·엔진 선정 관통.

남은 것: 4단계 통합 (cargo 나선 — Watson 중량+Holtrop 저항+실물
추진을 design_spiral에 배선, 100 m 첫 설계 리포트) + 엔진 실물
승급(수집 프롬프트 C)·반류 Holtrop 부속식.
