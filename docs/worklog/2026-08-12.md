## 발견 1 — 알루가 1.4배 과소설계였음

기존 코드가 **용접 항복 σ_yw 125를 허용응력처럼** 사용 (f1=125/235
→ 175·f1 = 93). 그러나 ISO 정본 설계응력은 **σ_d = 88** (=0.7·
σ_yw). 알루 배가 허용응력을 과대하게 잡아 과소설계였음. materials.py
에 design_stress_nmm2 필드 추가, 게이트가 σ_d 있으면 그것을 허용
으로 (강은 None → IACS 175·f1 유지). 재료 **C급 → B 승급**. 좌굴
σ_F는 항복 125 유지 (Johnson-Ostenfeld는 실제 항복 기준 — 정합)

## 발견 2 — 백지 리뷰가 알루 좌굴 E 버그 검거 [상]

# 보강재 좌굴 하드 게이트 (KS V ISO 12215-5) — 판 좌굴의 완결 (38일차 후속)

판 좌굴은 하드 게이트였으나 **보강재 좌굴은 "한계 공식만 보유·
게이트 미구현"** 상태였음 (단면 모델이 보강재를 덩어리 면적
a_long으로만 잡아 웨브 기하 h_w·t_w가 없어 세장비 검사 대상 부재).
이번에 보강재 기하 모델을 세워 게이트화.

- **stiffener.py 신설**: design_flat_bar_stiffener — 요구 단면계수
  Z_req(선저 압력) 만족 + 웨브 세장비 h_w/t_w ≤ 0.50·√(E/σ_yw)
  (표 B.2 §1)인 최소 플랫바를 웨브 증육으로 설계. 바 단독
  Z=t_w·h_w²/6000 cm³ (부착판 무시 보수적 C급, T/L은 경량)
- **girder 단면 분리 설계**: a_long(hull girder 단면계수)는 안
  건드리고 별도 국부 보강재만 → NSGA 파급 0. strength 게이트가
  선저 요구 Z로 보강재 설계·세장비 판정, 종합 passed에 반영
- 첫 판정: 100m 강 웨브 204×15mm(세장비 13.6/14.8)·30m 알루
  117×10mm(11.7/11.8). **알루 E 낮아(70000) 세장비 한계 엄격 =
  같은 Z에 웨브 두꺼움** (물리 정합)
- **백지 리뷰 정직 처리**: σ_d(88) 사용 제안 **기각** — 표 B.2 §1
  공식이 문자 그대로 σ_yw이고 §2 사전계산값(알루 12) 역산이
  σ_yw=125 확증 (σ_d 88이면 한계 14.1로 표값 12와 불일치).
  수리 2건: 실패 경로(거대 Z) 치수 오염 → t_w 상한 고정·h_w
  재계산 정합, "항상 수렴" 과장 → 통상 Z·60mm 한정 명시
- 정직 범위: 플랫바 웨브 세장비만 (T/L·top hat·기둥·전단 좌굴
  미구현 C급). 보강재 좌굴 게이트 각주 "미구현" → "구현" 갱신
- 백로그: 보강재 T/L 프로파일·전단 좌굴·a_long 마법숫자를 실제
  보강재 단면적 연동 (girder 통합)

# 보강재 T/L 프로파일 + 전단 좌굴 — 플랫바에서 실선 T바로 (38일차 마무리)

플랫바 보강재의 후속. 실선은 T/L 프로파일을 쓰는데, 이유가
표 B.2 §1에 있음: **T웨브는 전단 좌굴 기준** h_w/t_w ≤ 1.29·
√(E/τ_yw) (τ_yw=σ_yw/√3)이라 플랫바(0.50·√(E/σ_yw))보다 훨씬
슬렌더 허용 (강 T웨브 50 vs 플랫바 15·알루 40 vs 12) — 플랜지가
웨브를 지지하므로.

- stiffener.py 추가: stiffener_web_shear_slenderness_limit(전단)·
  stiffener_flange_slenderness_limit·tee_section_modulus(T단면
  평행축 합성)·design_tee_stiffener(등두께·b_f=0.4h_w·h_w 이분).
  §2 값 강 50·알루 40 재현
- 게이트를 플랫바 → **실선 표준 T바**로 전환: 같은 Z=150에
  플랫바 37.9 cm² vs T바 29.0 cm² = **24% 경량** (웨브 296×7 vs
  237×16). 실선 T/L의 존재 이유 수치화. NSGA 파급 0(국부 보강재)
- **백지 리뷰: 물리 결함 0** (5축·§2값 재현 확인). 지적 2건 [하]:
  헤더 문서 T바 미기술→보강, 플랜지 게이트 비구속(b_f=0.4h_w에선
  웨브 지배)→의도 명시
- 정직 범위: T바 웨브 전단·플랜지 세장비 (top hat·기둥 좌굴·
  부착판 유효폭 미구현 C급). 백로그: a_long 실보강재 연동·top hat

# ISO 표 17 판재/보강재 분리 + FRP 정본화 — 오늘 캡처의 즉시 수확

## 발견 1 — 판재와 보강재 설계응력이 다르다

표 17: 알루 **판재** σ_d = min(0.6·σ_uw, 0.9·σ_yw) = min(165,
112.5) = **112.5** / **보강재** 0.7·σ_yw = 87.5. 종강도(hull
girder) 허용은 갑판·선저 **판재 극한섬유**라 판재값이 정본 —
어제 넣은 88(보강재값)은 25% 과보수였음. Material에
design_stress_plate_nmm2 분리 필드 추가

## 발견 2 — FRP 정본화 (C급 → B)

표 C.9 (E-glass/폴리에스터 손적층 CSM, ψ=0.30): E 8267·G 2943·
σ_ut 112·σ_uc 141·σ_uf 155·τ_u 59. 표 17 (k_BB 1·k_AM 0.9):
