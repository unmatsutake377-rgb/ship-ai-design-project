자율운항 선박 설계 자동화 PoC
통합 시스템 명세 및 온보딩 가이드

대상 독자: 프로젝트를 돌아보는 미래의 '나', 그리고 프로젝트에 처음 합류하는 팀원 및 기여자
문서 상태 (2026-07-30 기준): 본 문서는 PoC 파이프라인의 설계 철학, 물리적 검증 내역, 그리고 인지된 기술 부채를 투명하게 기록한 단일 진실 출처(Single Source of Truth)입니다. 코드를 읽기 전 반드시 전체 아키텍처의 흐름을 파악하는 지도로 활용하십시오.

1. 프로젝트 개요

  • 최종 목표: 사용자가 운항 목적(용도, 탑재량 등)을 입력하면, 물리적으로 검증된 최적의 선형 후보들을 자동 생성하고, 이를 즉시 ROS2/Gazebo 시뮬레이션 환경에 투입해 자율운항 알고리즘 테스트까지 직결시키는 End-to-End 파이프라인 구축.
  • 주요 타겟: 1~3m급 소형 무인수상정(USV). 배수량형·반배수량형·활주형 세 속도 체계 전부 지원 (Phase C-2, 2026-07-30). 조사용(Survey) USV를 데모 시나리오로 활용.
  • 개발 및 검증 규율: 모든 물리 모듈은 해석해, 문헌, 혹은 독립 구현 대조를 통한 '정답지 있는 검증'을 통과해야 병합됨 (현재 pytest 172개 전수 통과).
  • 개발 환경: macOS Apple Silicon, Python 3.13, Docker Desktop (ROS2용).

2. 전체 시스템 아키텍처

Phase A 완료 선형 설계, 검증 및 최적화

단일 명령어(python -m src.pipeline --payload 100 --purpose survey)로 실행되는 선형 탐색 공정입니다.

모듈 역할 및 기능 검증 근거
ai/presets 용도(Purpose) 선택 시 실선 통계 기반 순항 속도 자동 할당 데이터 및 개략 출처 표시
ai/dimension_estimator 실선 USV 통계(L/B≈2.0 등) 기반 치수 추정 및 제약 세팅 실선 데이터 CSV 자동 심사
physics/hydrostatics 평형 흘수 역산, GM/B 밴드(0.04~0.40) 필터링 직육면체 바지선 해석해 대조
physics/resistance ITTC-57 마찰 저항 + Michell 박선이론 조파 저항 계산 Wigley 벤치마크 및 이중 검증 (해석해 대비 0.3~0.6%, 원저자 독립 구현 대비 비 0.93~1.00)
physics/coefficients Fossen 3자유도 조종 계수 도출 (Clarke 회귀 분석) 차원 스케일 대조 및 음수 관성 발산 방지 클램프
최적화 계층 (M5) NSGA-II 다목적 최적화 및 Ship-D 데이터셋 3만 척 대리모델(MLP) 초고속 가상 선별 → 상위 모델 물리 재검증 재검증 원칙에 따른 100% 실물리 무오염 데이터
HITL (ELO) 인간 개입(Human-in-the-loop) 파레토 쌍대비교 랭킹 산출 ELO 성질 테스트 7종 통과

Phase B 완결 ROS2 및 시뮬레이션 통합

  • B-1 (완료): Mac Docker 기반 ros:jazzy 이미지 토픽 통신 확인. 설계 결과를 URDF 및 유체계수 YAML로 자동 변환 (컨테이너 내 check_urdf 파싱 성공).
  • B-2 (완료): Gazebo Harmonic 스폰 + 부력 교차 검증 — 바지선 정착 흘수가 해석해와 0.1mm 합치.
  • B-3 (완료 🏁): ros_gz 브릿지 + rclpy 제어 노드(LOS+고유값 게인) — 설계된 배가 사각 코스 자율 완주 (520 사이클 · 0.77 m/s · 직선 이탈 σ 0.22m). gz 실측 거동 10건 문서화.

Phase C 진행중 유체 해석 고도화 및 고속선 확장

  • C-1 (완료): 반배수량(Fn 0.4~1.0) 개방 — 트랜섬 선미 파라메트릭 계열 + 메쉬 Michell + 트랜섬 기저항. 고속 순찰 USV 설계 가능.
  • C-2 (완료, 2026-07-30): 활주 체계 개방 — Savitsky 1964 경험식 평형(트림·젖은길이·저항) + V바닥 데드라이즈 선형(β=15°) + 활주용 GM/B 밴드. 이로써 세 속도 체계 전부 설계 가능. 정직성 메모: 원논문 수치예제 미입수로 공식 전사 + 자기일관 + 물리 경향 3층 검증까지만 완료 (정량 대조는 문헌 확보 시).
  • CFD 훅 (완료, 2026-07-31 — 원안 Step 5, 마지막 조각): 설계 산출물 → OpenFOAM 케이스 자동 생성(케이스 템플릿 + 이중모형 절단) → Docker 실행(simpleFoam 단상 / interFoam 자유수면) → force 로그 파싱(수렴 판정) → data/cfd_labels.csv 라벨 축적. Wigley 실증: 격자 77,721셀, 단상 점성 5.3 N vs ITTC-57 7.6 N / 자유수면 전체 16.4 N vs 경험식 28.9 N (모두 자릿수 일치 — 거친 격자라 정량 일치는 미주장). 부수 발견: 통통한 배(L/B=2)에서 Michell 조파저항의 '얇은 배' 가정 위반이 ~5배 과대예측으로 정량 관측됨. 이로써 원안 6단계 전부 최소 1회 실증.
  • 능동 학습 1회전 (완료, 2026-07-31): L/B 스팬 3척 CFD(6런 병렬)로 Michell 보정 계수 ratio_w(B/L) 적합 시도 → 직선 가설 기각 — 거친 격자가 날씬한 배의 작은 파도를 수치 감쇠시켜 관측이 오염됨 (L/B=10 조파 추정이 Michell의 6%). 계수는 미채택하고, 루프가 지목한 다음 실험 = 격자 수렴 연구로 방향 전환. "다음 실험을 데이터가 고른다"는 능동 학습의 본질이 부정적 결과의 형태로 시연됨. 배관(표본→CFD→적합→재평가)은 전 구간 관통 — 격자 개선 후 명령 1줄로 재회전.
  • MaxBox 탑재 공간 제약 (#27 완결, 2026-07-31): 선체 내부 최대 직육면체(MaxBox)와 짐 부피(용도별 밀도 환산 또는 직접 입력)를 비교하는 4번째 필터 — 무게 검사(아르키메데스)가 놓치던 "부피가 물리적으로 들어가나"를 메움. 오너 결정: 공간은 목적함수가 아니라 제약("용도는 사용자의 마음, 우리는 구현 가능성 판단").
  • 진행 중: 격자 수렴 연구 (전체 1.5배 refine × L/B 4·10, 능동 학습이 지목한 실험 — 실행 중). 남은 확장: 자유 자세(트림·부상), 활주·반배수량 CFD 케이스, 반배수량·활주용 Gazebo 내보내기(현재 배수량형 기준).

3. 데이터 흐름도 (Data Flow)

[입력] 용도(survey/patrol/workboat) + 탑재량(kg) + 선택 조건(LOA, Speed) ↓ [P1: 제약 세팅] 용도 프리셋 → 실선 통계 치수 기반 3체계(배수량/반배수량/활주) 판정 ↓ [P2: 설계·검증] 선형 생성(Wigley/Ship-D) → 설계 나선 수렴(중량↔흘수↔저항↔모터) → 필수 물리 필터 ↓ [P2b: 대량 탐색] 대리모델(MLP) 3만 척 가상 스캔 → 상위 후보만 실물리 재검증 → 합산 파레토 전선 도출 ↓ [P3: 인간 선택] 파레토 후보들에 대한 쌍대비교(ELO 랭킹)를 통한 직관적 최종 모델 확정 ↓ [출력] 최종 선형 STL, 파레토 CSV, ROS2용 URDF, 유체계수 YAML, 웨이포인트 궤적 플롯

4. 인지된 시스템 한계 (Known Issues & Tech Debt)

본 프로젝트는 한계를 숨기지 않고 투명하게 기록하여 고도화의 나침반으로 삼습니다.

  • Michell 박선이론 한계: 트랜섬 선미 후방의 유동 박리저항을 수학적으로 모델링하지 못해 Ship-D 류 선형의 저항이 과소평가될 수 있음. 잔잔한 물 가정으로 내항성(파랑) 미평가.
  • 대리모델(MLP) 소표본 문제: 45차원 매개변수 학습 시 초기 라벨 부족으로 회귀 R²가 저조함. (대책: 시스템 구동을 통한 정상 라벨 축적 및 재학습 루프 가동).
  • 실무적 운송 지표(갑판 면적) 누락: 현재 저항/중량/안정여유 3축 최적화로 인해 '탑재 공간(MaxBox)' 요소가 알고리즘에 반영되지 않음. (백로그 등록됨: 4번째 목적 함수 vs 필수 제약 — 미결정, 오너 논의 예정).
  • 조종 계수 외삽 주의: 대형 상선(B/L 0.1~0.2) 데이터를 USV(B/L~0.5)에 외삽함에 따른 수학적 발산 위험. (대책: 음수 관성 방지 클램프 및 상시 경고 플래그 적용 중).
