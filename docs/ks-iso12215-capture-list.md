## ⭐ 우선순위 1 — FRP(복합재) E-glass 표 (부록 C 계열)

현재 FRP는 초안(ISO/DIS 2004)값만 확보한 C급. 2019 정본으로 확정.

| 찾을 것 | 정확히 뭘 읽나 |
|---|---|
| **부록 C — E-glass 적층 기계적 특성표** | 단일 스킨 E-glass의 극한 인장 σ_ut·압축 σ_uc·**굽힘 σ_uf**·전단 τ_u·탄성계수 E — 유리질량비 ψ의 함수식 (초안은 σ_uf=502ψ²+107 형태) |
| **공칭 유리질량비 ψ 표** | 손적층 CSM·Woven Roving·다축포별 ψ 기본값 (초안: CSM 0.30·WR 0.48) |
| **FRP 설계응력 계수** (표 8·15 계열) | 판 σ_d = (몇)·σ_uf, 보강재 σ_d = (몇)·σ_ut/σ_uc, τ_d = (몇)·τ_u (초안: 판 0.5·σ_uf) |

→ 확보 시: 우리 FRP σ_d 100·E 15000 정정 (초안 기준 σ_d~67·CSM E~6400
or WR E~13240 — 정본으로 확정). 현재 미사용 재료라 급하진 않으나
C급 각주 완결.

## 우선순위 2 — 소형선 설계 압력식 (본문 8절 계열)

현재 우리 소형 압력은 DNV/IACS 대형식 차용 → 소형 전용식으로 정밀화.

| 찾을 것 | 정확히 뭘 읽나 |
|---|---|
| **선저 설계 압력** | 활주형·배수량형 구분 압력식 P_bottom (설계범주 계수 k_DC·중력가속 계수 n_CG 등 포함) |
| **선측·갑판 설계 압력** | P_side·P_deck 식과 최소값 |

## 우선순위 3 — 판 두께식 계수 (본문 9~10절)

| 찾을 것 | 정확히 뭘 읽나 |
|---|---|
