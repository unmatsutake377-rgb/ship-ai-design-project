## 🟠 이번 캡처 목표 — 소형 설계압력 + 판두께 캠페인

우리 소형 압력이 대형(DNV/IACS)식 차용 중 — ISO 소형 전용식으로
승급하는 데 필요한 것. **7절(계수) → 8절(압력) → 10절(판두께)**
순서로 찾으면 됨.

### A. 압력 계수 (7절) — k_DYN·k_L은 확보, 나머지 3개

| # | 찾을 것 | 뭘 읽나 |
|---|---|---|
| A1 | **설계범주 계수 k_DC** (7절 초반) | 범주 A(원양)/B(근해)/C(연안)/D(보호수역)별 계수 값 4개 |
| A2 | **면적 압력 감소 계수 k_AR** (7절) | 공식 (k_R·설계면적 A_D 관련) + 최소값. 패널이 클수록 압력↓ 보정 |
| A3 | **k_Z (선측 깊이 분포)** (7절 후반, 있으면) | 선측 압력의 수선~건현 높이 보간 계수 |

### B. 설계 압력 본식 (8절) — 핵심

| # | 찾을 것 | 뭘 읽나 |
|---|---|---|
| B1 | **8.1 모터보트 선저 압력** | 배수량 모드 P_BMD·활주 모드 P_BMP 두 공식 전체 (m_LDC·L_WL·B_C·k_DYN 조합) + 최소값 |
| B2 | **8.2 선측 압력** | P_SM 공식 + 최소값 |
| B3 | **8.3 갑판 압력** | P_DM 공식 + 최소값 (기존 추정 5 kN/m² 대조) |
| B4 | (선택) 8.5 상부구조·수밀격벽 압력 | 있으면 |
