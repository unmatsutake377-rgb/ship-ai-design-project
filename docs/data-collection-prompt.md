# 실선 데이터 수집용 AI 프롬프트 (#17 상시 — 복붙용)

외부 AI(웹 검색 가능한 것 권장)에 아래를 그대로 붙여넣어 사용.
수집 결과는 오너가 출처 URL을 직접 열어 확인한 뒤에만 data/에 반영
(관례: 실패 박물관 "외부 AI의 창작" — AI 산출물은 검수가 기본).

---

## 프롬프트 A — 실선 (무인정/소형정 주요치수)

나는 선박 설계 데이터베이스를 만들고 있어. 실제로 판매·운용되는
조사선/순찰선/작업선(무인·유인 불문)의 **공식 스펙**을 찾아줘. 조건:

1. **대상**: 크기 제한 없음 — 소형정부터 중대형 조사선·순찰정·
   작업선까지 (오너 결정 08-06: 크기는 조건이 아님). 용도는
   조사(survey)/순찰(patrol)/작업(workboat) 중 하나로 분류.
   다양한 크기 대역(수 m급/수십 m급)을 섞어서. 이미 보유:
   Otter(Maritime Robotics), Z-Boat 1800(Teledyne),
   Heron(Clearpath), SR-Surveyor 계열, Apache 계열 — 이들 말고.
2. **필수 항목** (모르면 반드시 빈칸 — 추정치 금지):
   전장 LOA[m], 폭 beam[m], 흘수 draft[m], 자중[kg], 만재중량[kg],
   최대 탑재 payload[kg], 최고속도[m/s 또는 kn], 순항속도, 선형
   (단동/쌍동), 제조사.
3. **출처 규칙 (가장 중요)**:
   - 각 항목의 출처 URL을 반드시 병기 — 제조사 공식 페이지나 공식
     데이터시트 PDF만 A급, 리셀러/기사 인용은 B급으로 표시
   - **찾지 못한 값은 절대 지어내지 말고 빈칸으로** — 빈칸이 많아도
     배 한 척의 확실한 값이 추정치 열 개보다 가치 있어
   - 단위를 원문 그대로 적고 (kn인지 m/s인지), 환산했으면 환산
     과정 표기
4. **출력 형식**: 아래 CSV 헤더에 맞춘 표 + 각 행 아래 출처 목록

```
name,maker,category,hull_type,loa_m,beam_m,draft_m,weight_light_kg,weight_full_kg,payload_kg,speed_max_ms,speed_cruise_ms,source_url,source_grade,notes
```

5개 척만, 대신 확실하게.

## 프롬프트 B — 논문/문헌 (설계 계수·실험 데이터)

나는 선박 설계 파이프라인의 물리 모델을 문헌 실측으로 검증하고
있어 (크기 불문 — 소형정부터 중대형까지). 다음 주제의 **논문 또는 공식 기술문서**를 찾아줘:

- 주제(하나 골라 사용):
  a) 선박 저항 계측 실험 (모형시험 또는 실선 시운전 —
     속도-저항 곡선이 표/그래프로 있는 것)
  b) 안정성 기준 (GM/B 권장 범위 — ISO 12217, IMO IS Code 등 크기별 규정)
  c) 반배수량/활주 경계 영역의 트랜섬 선미 설계 (Cp·Cm·트랜섬
     침수면적 데이터)
  d) 방향타 설계 (러더 면적비·양력계수 실측 — DNV 등 선급 규정 포함)

요구사항:
1. 논문 제목·저자·연도·게재지(또는 DOI/링크)를 정확히 — **존재가
   불확실한 논문은 "불확실" 표기** (지어낸 서지사항이 최악)
2. 각 문헌에서 내가 쓸 수 있는 **구체 수치**가 뭔지 한 줄 요약
   (예: "Fn 0.2~0.5 구간 저항계수 표 있음")
3. 무료 접근 가능 여부 (오픈액세스/프리프린트 링크 우선)
4. 5건 이내, 관련도 순.

## 수집 후 처리 절차 (오너용 체크리스트)

1. AI가 준 출처 URL을 **직접 열어** 값이 실제로 그 페이지에 있는지
   확인 (없으면 그 행 폐기 — 교차검증 전이면 cross_verified=False)
2. data/small_craft_particulars.csv 형식에 맞춰 추가 (collected_date
   기입, 파생 계산값은 notes에 계산 과정)
3. 논문 수치는 사용할 모듈의 스펙 문서에 출처와 함께 기록
4. 세션에서 "실선 N척 추가했어" 하면 치수 추정기 재캘리브레이션
   여부를 판단해줌

## 프롬프트 C — 대형 엔진 (전 크기 개방 3단계)

나는 선박 설계 도구의 엔진 카탈로그를 만들고 있어. 실제 판매되는
**선박용 디젤 엔진**(중속·저속, 500 kW ~ 30 MW 대역)의 공식 스펙을
찾아줘: 모델명, 제조사(MAN Energy Solutions·Wärtsilä·HiMSEN 등),
MCR 출력[kW], 건중량[t], SFOC[g/kWh], 정격 회전수[rpm]. 규칙은
프롬프트 A와 동일 — 제조사 공식 페이지/프로젝트 가이드 PDF만 A급,
못 찾은 값은 빈칸, 항목마다 출처 URL. CSV 헤더:
`name,maker,mcr_kw,mass_t,sfoc_g_per_kwh,rpm,source_url,source_grade,notes`
5종, 출력 대역이 겹치지 않게 분산해서.
