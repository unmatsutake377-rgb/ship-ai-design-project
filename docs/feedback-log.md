  ② "바꿨는데 그대로" → 그림 경로 배선 누락 검거 + 단면 겹침 뷰
  ③ "선수미가 동일" → 비대칭 기본 승격 (오너 결정 "바꾼 걸 메인으로")
- **패턴**: 오너의 시각적 감식안이 수치 검증이 못 잡는 결함을 연속
  발굴 (지뢰 발굴 4호까지) — 영상·형상 산출물은 오너 눈을 정식 검증
  단계로 취급할 것.
- **How to apply**: 형상·매체 변경 시 비포/애프터를 먼저 보여주고
  진행. "물리 따로 그림 따로" 방지 — 파라미터 소비자에 시각화 경로
  포함.
