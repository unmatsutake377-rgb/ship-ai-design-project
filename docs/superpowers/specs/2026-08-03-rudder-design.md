# 러더(방향타) 설계 옵션 — 조타·추력 분리 (2026-08-03)

- 상태: 오너 승인 (깊이 = 정식 설계 옵션 / 구성 = 둘 다 옵션)
- 유래: 배분 재설계 2안 계측 기각(8/3)으로 확정된 구조 한계 —
  "전진 전용 추력기 쌍에서 조타 = 추력" (기하 제약 |차동| ≤ 전진합).
  자기지속 루프(요동→차동→전진력→과속→요동)의 하드웨어 층 해법.

## 1. 물리 모형 (시뮬 공통)

러더 = 물살 속 양력판 (표준 평판 모형):
- 양력 L_r = ½·ρ·V_r²·A_r·C_L(δ),  C_L = 2π·k·δ (소각 선형, 실속
  |δ|>δ_stall 에서 포화) — V_r: 러더 위치 유속(≈u), δ: 타각
- 조타 모멘트 N_r = −L_r·x_r (x_r: 선미 러더 위치, ≈ −0.48L)
- 핵심 특성 "물살 없으면 무력"이 V² 항으로 자연 재현 — 저속 조타는
  차동이 보완 (구성 A의 존재 이유)

상수 — 3단계에서 실측 승격 완료 (출처 data/rudder_servo_specs.csv):
- 양력 기울기 = Mandel(1967) CLα = 1.8π·ΛE/(√(ΛE²+4)+1.8),
  ΛE = 2×기하 종횡비 (선체 밀착 거울 효과) [Liu & Hekkenberg 2017]
- 면적 = max(DNV 1975 최소, 요구 모멘트 역산) — 느린·불안정 선체는
  역산이 이김 (조사선 DNV×2.6), 빠른 배는 DNV 여유 (V² 항)
- δ_max = 35° (실선 관행), δ_stall = 17.5° (개수면 15~20° 중앙 —
  후류 무시 모형과 일관; 후류 모형 추가 시 30~40°)
- 서보 속도 375°/s 무부하 (Power HD 20kg·cm 방수) — 타각 변화율 제한

## 2. 구성 옵션 (오너: 둘 다)

- A "diff2+rudder": 차동 2발 유지 + 러더 — 순항 조타는 러더(추력
  오염 0), 정지·저속은 차동 보조. 서로의 약점을 메움 (실선 표준)
- B "single+rudder": 단일 추력기 + 러더 — 경량·저비용, 저속 조타
  상실·제자리 선회 불가 트레이드오프

## 3. 단계

1. **가설 검증** (이번 회차): python_sim에 러더 상태(δ) + 힘 모형 +
   러더 우선 제어(순항: δ로 조타, 차동 0) — 구성 A.
   **판정관 = 저속 추종 시험**: u_desired 0.77 명령 시 평균 u가
   0.77±20% (구식 배분은 1.40 고착 실측) + 기존 코스 품질 무회귀
2. 정식 통합: --steering 옵션, 구성별 조종성 리포트 비교, 노드 확장
3. 실물 데이터: 서보·러더 스펙 A급 수집 → 상수 교체
4. (후속 대형) Gazebo LiftDrag 플러그인 검증 — 이번 범위 밖 명시

## 6. 4단계: Gazebo LiftDrag 러더 (2026-08-03 착수 — 오너 승인 "(a) 정공법")

목적: 러더 결론의 교차 검증 — gz는 우리가 안 만든 물리 엔진이므로
LiftDrag 플러그인이 **자기 방식으로** 양력을 계산한 결과가 파이썬
1단계 판정(차동 폭주 vs 러더 추종)을 재현하면 독립 증거.

구성 (SDF, 구성 A = 차동 2발 + 러더):
- 러더 링크 (얇은 판) — 선미 x=−0.48L, 킬 근처. 크기 = 3단계 사이징
  (max(DNV, 요구 모멘트 역산)) 그대로
- revolute 조인트 (z축, ±35°) + JointPositionController (서보 역할)
- LiftDrag 플러그인: fluid density 1025, cla = Mandel 기울기,
  실속 17.5°, forward=+x·upward=+y (수직 핀 → 횡양력)
- waypoint_controller: steering=rudder2 — 모멘트→타각 역산 (파이썬
  1단계와 같은 법칙), 잔여만 차동 (전진 전용), 타각 매 틱 재발행

판정관: 조사선 gz — ① 저속 0.77 명령: 차동 과속 고착 vs 러더 추종
② 목표 속도 코스 완주 + σ 비교. 이번 회차 = 조사선 1척까지,
활주정·비교 리포트는 다음 회차.

정직 리스크: LiftDrag 부호·파라미터 늪 가능 — 막히면 실측 기록 후
축소판(힘 주입)으로 후퇴 선언.
