# 설계 지도 — 8중 게이트 시대의 설계 탐색 (2026-08-09)

- 상태: 오너 "물어보는 것 제외 계속" 자율 위임 — 자율 설계.
  선정 근거: 오늘 완성한 8중 게이트·EEDI·연료비·CII가 아직 "한 척
  판정" 전용 — 탐색 축으로 돌리면 "목적 → 후보 지도 → 합격 중
  최적 추천"이 완성됨 (프로젝트 원안 "AI 주도 목적 지향"의 종합).
  새 물리 없음 = 리턴 확실성 최상. 기각: 쌍동선 (4캠페인 전부
  쌍동 분기 — 폭 과대, 검증 실선 1척), 제품화 (학습 리턴 낮음 —
  오너 기존 판단 계승)

## 1. 배경

- 오늘 발견: 13.6kn 프리셋 EEDI 불합격 → 11.7kn 합격 (수동 민감도)
- 일반화: **속도 × 짐(DWT)** 격자 전체를 8중 게이트로 평가 →
  "합격 설계들의 지도" + 추천 (합격 ∧ 수송단가 최소)
- 규모의 경제 가설 검증: 큰 배가 t·nm당 싸다 — 기준선 a·DWT^−c의
  물리적 근거를 우리 사슬로 재현하는지

## 2. 구조

- `src/ai/design_map.py`:
  - `evaluate_design(payload_kg, speed_ms, purpose="cargo",
    fast=False) -> dict` — run_pipeline 호출 (임시 디렉터리),
    핵심 지표 추출: loa·passed·게이트별 합불·EEDI margin·CII 등급·
    연료비·수송단가. fast=True는 느린 게이트(내항·조종) 생략
    (탐색용 — 최종 추천만 전체 게이트 재검)
  - `design_map(payloads, speeds) -> list[dict]` — 격자 순회
  - `recommend(results) -> dict` — 전 게이트 합격 중 수송단가 최소
    (동률 시 EEDI 여유 큰 쪽)
- 성적표: 속도 4 (5.5/6.0/6.5/7.0 m/s) × 짐 3 (5k/8k/12k t) =
  12 설계 지도 → worklog 표 + 추천 설계 전체 게이트 재검

## 3. 검증 앵커

1. 단조 성질: 같은 짐에서 감속 → 수송단가 감소 (V² — opex 검증
   재사용, 지도 차원에서 재확인)
2. 규모의 경제: 같은 속도에서 짐 증가 → 수송단가 감소 방향
3. EEDI 경계 재현: 속도 축에서 합격/불합격 경계가 1단계 수동
   민감도(11.7kn 근방)와 일치
4. 추천 설계 = 전체 8중 게이트 실검 합격 (fast 탐색과 전체 검증
   일치 확인)

## 4. 관례·리스크

- 게이트 신설 없음 — 기존 8중 재사용 (평가 비용: fast 격자 ~수 분,
  전체 재검 1척 ~1분)
- 지도 산출물(CSV)은 outputs/ (커밋 금지 관례), 표는 worklog
- 리스크: 짐 축 상단(12k)에서 엔진 카탈로그 한계 가능 — 정직 거절
  도 지도의 정보 (설계 불가 영역 표기)
