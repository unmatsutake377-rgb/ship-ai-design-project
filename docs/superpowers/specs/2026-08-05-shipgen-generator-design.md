# ShipGen 생성기 채택 — 최고 품질 선형 경로 (2026-08-05)

- 상태: 오너 결정 "가장 퀄리티 높게 나올 수 있는 방안을 채택"
- 유래: 오너 제시 이미지(실선급 선수·선미) 대비 우리 수식 생성기
  손잡이 3개(Cb·Cm·LCB)의 표현 한계. Ship-D 파라미터화 = 정확히
  그 급 (선수 9항·선미 11항·벌브 14항·중앙단면 4항·주요치수 7항 =
  45파라미터 + 제약 49개, 3만 척 실값 분포 보유).

## 2. 단계

1. **생성 경로 개통** (이번): shipgen_generate(vector) → 메쉬 →
   설계 나선·4중 게이트 관통 검증. 데모 1척 선도(lines plan)로
   품질 확인 (오너 제시 이미지 대비)
2. **조건 → 문법 연속 매핑** (오너 철학 2026-08-05 확정): "크기와
   속도에 따라 전반적인 파라미터가 변경되는 형식" — 제트보트 조건이면
   활주 문법, 화물선 조건이면 대형·평행 중앙부 상선 문법이 자연
   출력. 고정 필터·일괄 프리셋 금지.
   - 구현: Ship-D 30,000척에서 형상 문법 지표(평행부 비율·D/B·LCB·
     선수 9항·선미 11항·벌브)의 **크기·속도 조건부 분포**를 학습 —
     입력 (용도·속도·짐) → 치수·Fn (기존) → 그 대역의 문법 분포에서
     후보 샘플/최적화
   - "소형정 문법"(1단계 데모 2)은 특례가 아니라 작고 느린 조건의
     자연 출력, "상선 문법"(데모 1)은 크고 느린 조건의 자연 출력
   - 활주(고Fn)는 Ship-D 분포 밖 — 기존 Savitsky V바닥 계열 유지
     (체계 디스패치의 문법 디스패치로의 확장)
3. 최적화 연결: NSGA 탐색 공간을 45파라미터(또는 부분공간)로 —
   기존 Wigley 4변수 전선과 A/B
4. 수식 생성기 강등: 검증 표준기 + 폴백으로 보존 (관례)

## 5. 2단계 결과 (2026-08-05 완결 — 양 축 실증)

구현 = `src/ai/shipgen_select.py`: 문법 규칙 0줄. goal 조건으로
표본 400척을 실측 평가(설계 나선 + 4중 게이트), 통과자를
`condition_weights`(용도 프리셋 × Fn² 저항 증폭)로 선별 — 문법은
데이터에서 발현.

- **짐 축 (1차)**: 무거운 조건(0.8 m/s·180 kg·workboat) → L/B 3.1
  통통·229 kg 몸집 자동 선택. 표준 조건은 L/B 3.8 날씬.
- **속도 축 (2차)**: 1차 실패(승자 고정) 원인 = 안정 이중 계상
  (게이트가 GM 밴드 보장하는데 점수도 안정 0.45) → 프리셋 가중 +
  Fn² 증폭으로 처방. 판정: 0.9·1.3 m/s 승자 hull 900(L/B 5.6
  안정형), 1.8 m/s 승자 hull 29813(L/B 3.8 저저항형) — **역전 지점
  Fn 0.24~0.33, 저속=안정 우선·고속=저항 우선**이 규칙 없이 발현.
- 사고 기록: "1.8 전멸"은 macOS 권한 사고의 오염 (재계측 134/400
  통과) — 전멸 데이터는 인프라 무죄 먼저. worklog 08-05 참조.
- 남은 조각: 파이프라인 정식 편입(`--hull-source shipd`)은 3단계
  (NSGA 45파라미터)와 함께.

## 6. 3단계 결과 (2026-08-05 완결 — 부분공간 채택)

`src/ai/shipgen_optimize.py`: NSGA-II, 경계 = 실값 분포(하드코딩 0),
초기 개체군 = 실척 시드, 제약 49개 위반 즉사 + 사망 사유 카운터.

- 1차전 45 전차원: 제약 사망 66%, Wigley에 0승 10패 — 자유 탐색
  부담 실측 (정직 기록)
- 2차전 부분공간 11차원 (주요치수+중앙단면 자유, 선수미·벌브 =
  기준 척 고정): 제약 사망 13%, **Wigley 24척 중 12척 지배·역피지배
  0** — 같은 저항에 ~10 kg 경량. SUBSPACE_MAIN_MID 채택
- 남은 조각: 파이프라인 `--hull-source shipd` 편입(4단계와 함께),
  전차원 예산 증액 실험은 백로그

## 7. 4단계 결과 (2026-08-05 완결 — 조건부 강등)

`run_pipeline(hull_source="auto")`: 배수량에서 실척 선별 시도 →
**수식 기준선과 실측 A/B → 이긴 쪽 채택** (판정 사유 hull_note).
첫 데모에서 빠른 선별 승자가 수식 대비 저항 6.5배 완패 — 무작위
표본 z-상대평가의 함정 실측. 품질 방어(용도 가중 비율 종합, 안정은
게이트 몫) 없이는 강등이 곧 품질 후퇴였음. 반배수량·활주는 수식
유지 (Savitsky — 오너 철학). 수식 생성기 = 표준기 + 기준선 심판
(강등이지만 은퇴가 아니라 더 중요한 자리).
