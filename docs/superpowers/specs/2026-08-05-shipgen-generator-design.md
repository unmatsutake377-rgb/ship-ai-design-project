# ShipGen 생성기 채택 — 최고 품질 선형 경로 (2026-08-05)

- 상태: 오너 결정 "가장 퀄리티 높게 나올 수 있는 방안을 채택"
- 유래: 오너 제시 이미지(실선급 선수·선미) 대비 우리 수식 생성기
  손잡이 3개(Cb·Cm·LCB)의 표현 한계. Ship-D 파라미터화 = 정확히
  그 급 (선수 9항·선미 11항·벌브 14항·중앙단면 4항·주요치수 7항 =
  45파라미터 + 제약 49개, 3만 척 실값 분포 보유).

## 1. 라이선스 자세 (정직)

- GitHub 원저장소 LICENSE 파일 부재 (기본 저작권), Dataverse 지정
  미확정 — 명시 허가 없음
- 실질: 기존 선별 경로가 이미 이 코드로 메쉬 생성 중 — 생성기 승격은
  같은 사용 형태 (로컬 실행)의 연장
- 안전장치: ① 코드·데이터 재배포 금지 유지 ② 생성 선체 STL·렌더
  저장소 커밋/공개 금지 (라이선스 확정 전 — 오너 로컬 열람만)
  ③ 저자 문의는 백로그

## 2. 단계

1. **생성 경로 개통** (이번): shipgen_generate(vector) → 메쉬 →
   설계 나선·4중 게이트 관통 검증. 데모 1척 선도(lines plan)로
   품질 확인 (오너 제시 이미지 대비)
2. 3입력 매핑: 용도·속도·짐 → 45파라미터 — 초기안 = 3만 척 분포에서
   조건 맞는 이웃 샘플 + 국소 조정 (대리모델 v3.1이 게이트).
   **핵심 원칙 (오너 지시 2026-08-05): 배 종류마다 선수·선미 선형이
   전부 다르다** — 용도별로 선수 9항·선미 11항·벌브 14항의 분포를
   따로 캘리브레이션 (예: 저속 조사선 = 벌브 없음·풍만 선수·fine
   run / 작업선 = 트랜섬 풍만 / 고속 = fine 선수·트랜섬). 일괄
   프리셋 금지 — Cm·LCB 조각에서 확립한 "용도별 실측 근거" 관례를
   선수·선미 파라미터군 전체로 확장
3. 최적화 연결: NSGA 탐색 공간을 45파라미터(또는 부분공간)로 —
   기존 Wigley 4변수 전선과 A/B
4. 수식 생성기 강등: 검증 표준기 + 폴백으로 보존 (관례)

## 3. 검증

- 생성 메쉬 watertight + 제약 49개 통과 + 정역학·저항 관통
- 선도 육안 (오너) — "고급진" 판정의 최종 심급
- 기존 시험 무회귀

## 4. 리스크

- 45파라미터 매핑은 대공사 — 단계별 성적표 후 계속/중단 (관례)
- 파라미터화 코드 내부 미문서 영역 (실측으로 채움)
