# 다구획 MaxBox — 적재 공간 모형 + 분산 적재 (2026-08-03)

- 상태: 오너 승인 (설계 문답 4건 확정)
- 유래: #27 후속. 단일 상자 가정이 Ship-D 실선형에 과혹 (표본 15척
  feasible 붕괴) → 선별기 적용 보류. 실제 배는 구획 분산 적재.
- 오너 제안 반영: **"각 배마다 실제 적재 공간을 먼저 만들고, 그
  안에서 N개 자유로 채우면 확실한 부피와 무게가 나온다"** — 층
  구조(공간 모형 → 채우기 → 무게 되먹임)의 원설계가 오너 발상.

## 오너 결정 4건

1. 구획 수: **N개 자유 + 상자당 최소 치수** (종잇장 상자 방지)
2. 예약 구역: **중량 분포모델(M4a) 연동** — 무게 모형과 공간 모형이
   같은 배치도를 봄
3. 범위: **(c) 트림까지 전부** — 단, 러더 전례의 단계 캠페인으로
   (각 단계 성적표 후 오너 계속/중단 결정)
4. 적재 정책: **구간 판정** — 무게중심 도달 구간(배분의 1차 함수)과
   합격 구간의 겹침 검사. 탐색 없이 존재 판정 확정

## 1. 적재 공간 모형 (1층)

화물 공간 = 선체 내부 − 예약 구역.

- 예약 구역 위치 = M4a 상수 그대로: 추진(모터·배터리·전장) LCG
  −0.45L·VCG 0.25D → **선미 절단**: 선미쪽 x-구간을 통째 제외,
  구간 길이는 "그 구간 내부 부피 = 예약 부피"가 되도록 역산
  (부피 일치 절단 — 격자에서 직접 계산, 보수적·단순)
- 예약 부피 = 추진 질량 ÷ 배터리 밀도 1,843 kg/m³ (A급 실측,
  data/payload_items.csv) × 여유계수 3.0 (케이블·마운트·접근 공간 —
  명명 상수, #17 수집으로 승격 대상)

## 2. 다구획 채우기 (2층)

- 반폭 지형도 w(x,z)에서 예약 x-구간 제외 후 채움
- **구현 중 발견 2건 (2026-08-03 실측 반영)**:
  ① 내부 판정은 contains 격자 → **단면 절단법**으로 교체 — Ship-D
  비수밀 메쉬에서 contains 오작동 (정중앙 내부율 7% 물리 불가).
  단면 스캔라인 교차 보간 (z-빈 방식은 07-27 박제 버그라 금지).
  수밀 Wigley 대조 검증: 부피 오차 0.2%.
  ② 상자 천장 자유화 [z0, z1] — "천장 = 갑판" 가정이 위로 좁아지는
  Ship-D 선형에서 반폭을 0으로 몰던 과혹의 진범 (갑판층 내부율 8%).
- **반복 최대 직사각형**: 남은 x-구간에서 최대 상자 → 그 구간 소거
  → 반복. 칸막이는 지형도 골짜기에서 자연 발생
- 상자 채택 조건: 세 변 모두 ≥ MIN_BOX_DIM (0.25 m 개략 — 실측
  화물 참고: 배터리 0.15 m·플로트 패키지 0.8 m 폭)
- 판정: Σ상자 부피 ≥ 요구 짐 부피

## 3. 구간 판정 (3층 — 2·3단계)

- 짐을 구획들에 나누는 비율에 따라 짐 무게중심(z, x)이 구획 중심들의
  가중 평균으로 이동 — 도달 구간 = [구획 중심 최소, 최대] (1차 함수)
- 2단계 KG/GM: KG 도달 구간 ∩ GM 합격 구간 ≠ ∅ → 합격 배치 존재
- 3단계 트림: LCG 도달 구간이 LCB를 품으면 수평 배치 존재. 못 품으면
  자유 자세 정역학(침하+트림 2변수 평형, 기울인 물면 절단)으로 실제
  트림각 → 한계각 검사

## 4. 단계 캠페인

| 단계 | 내용 | 판정관 | 리턴 |
|---|---|---|---|
| 1 (이번) | §1+§2 부피 | Ship-D 표본 feasible 회복 계측 + 선별기 재개방 | 확실 |
| 2 | KG/GM 구간 | 1만 라벨에서 판정 뒤집힘 척 수 | 계측 후 |
| 3 | 트림 + 자유 자세 정역학 | 트림 과다 검출 + Wigley 손계산 정답지 | 계측 후 |

무회귀: 기존 단일 MaxBox는 Wigley 최적화기 경로 유지. 다구획은
Ship-D 경로 신설 (screen_shipd 보류 주석 해제가 1단계 종점).

## 5. 검증

- 손계산 정답지: 직육면체 껍데기 (예약 절단·구획 분할·부피 합·구간
  계산 전부 손 검산 가능)
- 종잇장 방지: 뾰족 쐐기 형상에서 최소 치수 미달 상자 기각 확인
- Ship-D 표본 재계측: 단일 vs 다구획 feasible 수 비교표
- 기존 시험 245 무회귀

## 6. 정직 한계

- 상자 축 정렬·중심선 대칭 가정 유지. 갑판 접촉은 해제 (§2 ②) —
  대신 **해치 접근성 무시** (짐 넣는 구멍 경로는 안 봄, 균질 주입)
