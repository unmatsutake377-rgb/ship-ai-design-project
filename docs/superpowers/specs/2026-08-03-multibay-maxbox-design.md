# 다구획 MaxBox — 적재 공간 모형 + 분산 적재 (2026-08-03)

- 상태: 오너 승인 (설계 문답 4건 확정)
- 유래: #27 후속. 단일 상자 가정이 Ship-D 실선형에 과혹 (표본 15척
  feasible 붕괴) → 선별기 적용 보류. 실제 배는 구획 분산 적재.
- 오너 제안 반영: **"각 배마다 실제 적재 공간을 먼저 만들고, 그
  안에서 N개 자유로 채우면 확실한 부피와 무게가 나온다"** — 층
  구조(공간 모형 → 채우기 → 무게 되먹임)의 원설계가 오너 발상.

## 오너 결정 4건

1. 구획 수: **N개 자유 + 상자당 최소 치수** (종잇장 상자 방지)
2. 예약 구역: **중량 분포모델(M4a) 연동** — 무게 모형과 공간 모형이
   같은 배치도를 봄
3. 범위: **(c) 트림까지 전부** — 단, 러더 전례의 단계 캠페인으로
   (각 단계 성적표 후 오너 계속/중단 결정)
4. 적재 정책: **구간 판정** — 무게중심 도달 구간(배분의 1차 함수)과
   합격 구간의 겹침 검사. 탐색 없이 존재 판정 확정

## 1. 적재 공간 모형 (1층)

화물 공간 = 선체 내부 − 예약 구역.

- 예약 구역 위치 = M4a 상수 그대로: 추진(모터·배터리·전장) LCG
  −0.45L·VCG 0.25D → **선미 절단**: 선미쪽 x-구간을 통째 제외,
  구간 길이는 "그 구간 내부 부피 = 예약 부피"가 되도록 역산
  (부피 일치 절단 — 격자에서 직접 계산, 보수적·단순)
- 예약 부피 = 추진 질량 ÷ 배터리 밀도 1,843 kg/m³ (A급 실측,
  data/payload_items.csv) × 여유계수 3.0 (케이블·마운트·접근 공간 —
  명명 상수, #17 수집으로 승격 대상)

## 2. 다구획 채우기 (2층)

- 반폭 지형도 w(x,z)에서 예약 x-구간 제외 후 채움
- **구현 중 발견 2건 (2026-08-03 실측 반영)**:
  ① 내부 판정은 contains 격자 → **단면 절단법**으로 교체 — Ship-D
  비수밀 메쉬에서 contains 오작동 (정중앙 내부율 7% 물리 불가).
  단면 스캔라인 교차 보간 (z-빈 방식은 07-27 박제 버그라 금지).
  수밀 Wigley 대조 검증: 부피 오차 0.2%.
  ② 상자 천장 자유화 [z0, z1] — "천장 = 갑판" 가정이 위로 좁아지는
  Ship-D 선형에서 반폭을 0으로 몰던 과혹의 진범 (갑판층 내부율 8%).
- **반복 최대 직사각형**: 남은 x-구간에서 최대 상자 → 그 구간 소거
  → 반복. 칸막이는 지형도 골짜기에서 자연 발생
- 상자 채택 조건: 세 변 모두 ≥ MIN_BOX_DIM (0.25 m 개략 — 실측
  화물 참고: 배터리 0.15 m·플로트 패키지 0.8 m 폭)
- 판정: Σ상자 부피 ≥ 요구 짐 부피

## 3. 구간 판정 (3층 — 2·3단계)

- 짐을 구획들에 나누는 비율에 따라 짐 무게중심(z, x)이 구획 중심들의
  가중 평균으로 이동 — 도달 구간 = [구획 중심 최소, 최대] (1차 함수)
- 2단계 KG/GM: KG 도달 구간 ∩ GM 합격 구간 ≠ ∅ → 합격 배치 존재
- 3단계 트림: LCG 도달 구간이 LCB를 품으면 수평 배치 존재. 못 품으면
  자유 자세 정역학(침하+트림 2변수 평형, 기울인 물면 절단)으로 실제
  트림각 → 한계각 검사

## 4. 단계 캠페인

| 단계 | 내용 | 판정관 | 리턴 |
|---|---|---|---|
| 1 (이번) | §1+§2 부피 | Ship-D 표본 feasible 회복 계측 + 선별기 재개방 | 확실 |
| 2 | KG/GM 구간 | 1만 라벨에서 판정 뒤집힘 척 수 | 계측 후 |
| 3 | 트림 + 자유 자세 정역학 | 트림 과다 검출 + Wigley 손계산 정답지 | 계측 후 |

무회귀: 기존 단일 MaxBox는 Wigley 최적화기 경로 유지. 다구획은
Ship-D 경로 신설 (screen_shipd 보류 주석 해제가 1단계 종점).

## 5. 검증

- 손계산 정답지: 직육면체 껍데기 (예약 절단·구획 분할·부피 합·구간
  계산 전부 손 검산 가능)
- 종잇장 방지: 뾰족 쐐기 형상에서 최소 치수 미달 상자 기각 확인
- Ship-D 표본 재계측: 단일 vs 다구획 feasible 수 비교표
- 기존 시험 245 무회귀

## 6. 정직 한계

- 상자 축 정렬·중심선 대칭 가정 유지. 갑판 접촉은 해제 (§2 ②) —
  대신 **해치 접근성 무시** (짐 넣는 구멍 경로는 안 봄, 균질 주입)
- 단면 별모양(y-단조) 가정 — 심한 오목 단면에선 반폭 과대 가능
- 짐 = 균질하게 부을 수 있는 근사 (개별 짐 모양·적재 순서 무시)
- 예약 부피 여유계수 3.0 개략 (실물 전장 배치 미수집)
- z0·z1(상자 바닥·천장)은 전 구획 공유 — 구획별 차등은 후속
- 라벨 호환: screen의 feasible(중량·안정) 의미 보존, space_ok 별도
  열 신설 — 기존 1만 라벨과 안 섞임 (파레토는 둘 다 요구)

## 7. 3단계 구현 노트 (2026-08-03)

- 트림은 자유 자세 완전판(기울인 물면 2변수 평형) 대신 **소각 선형
  이론** θ = (LCG−LCB)/GML, GML = KB+BML−KG — 표준 설계법이자
  완전판의 소각 근사. 한계각 2° 근방에선 정밀, 대각(>5°)은
  "크게 기운다"는 정성 판정으로만 신뢰 (정직 한계)
- 구조 LCG = 내부 부피 도심 근사 (Ship-D 비대칭 반영 — Wigley 중앙
  가정보다 개선), 추진 LCG = M4a −0.45L의 메쉬 프레임 사상
- GML의 KG는 도달 구간 중점 사용 — BML(수 m)이 KG(수십 cm)를 지배해
  오차 미미
- TRIM_MAX_DEG = 2.0 명명 개략 (실선 만재 트림 관리 관행 참조)

## 8. 후속 확장: 구획별 [z0,z1] 차등 (2026-08-03 완결)

- §6의 "z0·z1 전 구획 공유" 한계 해소 — 구획은 x-분할 유지(세로
  칸막이 원칙, 수직 적층은 여전히 범위 밖), 각 구획이 자기 z-띠 선택
- 알고리즘: 그리디는 동점 함정 실측 (낮고 넓은 상자의 전 구간 선점,
  계단 지형도 0.4 < 최적 0.6) → **x-분할 DP** (모형 내 최적 보장,
  칸막이 벌점 ε으로 동점 시 적은 구획, 구획 수 차원 포함)
- **MAX_BAYS = 4** 신설: 상한 없인 3 m 보트에 9칸 과관대 실측 —
  칸막이 중량·공사 미모형이라 개수로 현실성 방어 (종잇장 가드 철학)
- 계측 (표본 100척): 공간 69→76, 4중 게이트 최종 52→**68**, 적재
  부피 중앙값 0.355→0.387 m³. 2·3단계 구간 판정은 처음부터 구획별
  z를 받는 일반형이라 무수정 호환

## 9. 후속 확장 2건 (2026-08-03 완결)

**해치 접근성** (§6 한계 해소): 천장이 갑판에 안 닿는 상자는 위
목(neck)으로 짐을 내려보낼 수직 통로 필요 — 상자 x-구간 안에
"천장~갑판 전 층이 통과 가능(선체 없음=하늘 열림 or 폭 ≥ 최소치수)"
인 창(길이 ≥ 최소치수)이 있어야 채택. DP 구간값에 창 존재 조건 통합
(막힘 = 0<폭<최소치수 좁은 목만 — 반폭 0은 하늘 열림으로 통과).
정직 한계: 갑판 뚜껑 미모형 (선체 표면만 봄). 실측: 표본 100척 중
1척 기각 (Ship-D에 좁은 목 드묾 — 상식 부합).

**대각 트림 자유 자세** (§7 한계 해소): free_trim_equilibrium —
선체·무게중심을 트림각으로 통째 회전 → 수평 물면 배수량 평형 →
부심이 무게중심 바로 아래 오는 각을 이분법 탐색 (침하+트림 2변수
완전판). 상자 선체 대조: 소각에서 선형 이론과 일치 (2.28° vs 2.27°),
부호 검정 포함. 선별기는 선형 기각 배만 정밀 재판정 (비용 절제,
척당 평균 1.13 s) — 경계 사례(2°대) 구제, 잔여 기각은 전부 7~20°
진짜 곤두박질 (20° = 탐색 경계 = 복원 불능 표지).
