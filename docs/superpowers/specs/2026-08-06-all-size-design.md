- 상태: 오너 승인 (접근안 A — 단계 분할, "바로 가자")
- 유래: 오너 원칙 "크기는 사용자의 축 — 우리가 결정하는 게 아니다"
  (feedback-log 08-06). 소형(1~6 m) 초점은 데이터 가용성의 흔적.
- 목표 대역: **100 m+ 상선급까지** — 단 "정보가 너무 없으면 보류"
  (오너 게이트, 단계 성적표마다 판정)
- 오너 결정 3: ① 100m+ 목표+보류 게이트 ② **프로펠러까지 설계**
  (Wageningen B — 상상 부품 금지 계보) ③ 검증 = 공개 벤치마크 먼저
  + 오너 수집 통계 보강

## 1. 구조 원칙 — 크기 스위치는 없다

- 소형/대형 if 분기 금지 — **데이터가 자연 선택**:
  - 추진계: 카탈로그 통합 (전기 추진기 ~ 대형 디젤 한 표) — 소요
    동력이 알아서 고름
  - 저항: Michell vs Holtrop-Mennen을 **벤치마크 실측 A/B**로
    대역별 승자 결정 (ShipGen 4단계 품질 방어 관례 재사용)
  - 중량: 법칙별 유효 대역 명시 (소형 회귀 / Watson) — 벗어나면
    정직 표기
- 용도 **cargo(화물선) 신설** — "화물선 조건 → 대형 문법" 철학 입구
- 물리 심장부(정역학·안정·Ship-D 스케일)는 무차원 — 무수정

## 2. 1단계: 저항 + 벤치마크

- Holtrop-Mennen 구현: ITTC-57 마찰 + 형상계수(1+k1) + 경험 조파
  + 조파저항 유효 대역 (부가물·구상선수 항은 단계적 — 1차는 나선
  경로 핵심항)
- 검증: **KCS·KVLCC2 공개 수조 실측** Ct 대조 — 오차 대역 숫자 박제
- Michell 3자 비교: 상선급(Cb 0.65+)에서 얇은 배 가정의 실측 오차
  박제 → 대역별 승자 결정 (품질 방어)

## 3. 2단계: 중량·치수·게이트

- Watson-Gilfillan 강선 경하중량 (구조·의장·기관 분리) — 문헌 계수
- 상선 치수 대역: L/B 5.5~7, B/T 2.4~3.2, Cb 0.65~0.85 (문헌 통계
  — 출처 등급 B 시작, 오너 수집분으로 승급)
- 게이트: IMO IS Code GM 기준 + 건현 개략 (ICLL 계보) — 기존 GM/B
  밴드와 크기별 정합 검토
- 기존 소형 회귀는 유효 대역 명시 후 보존 (무회귀)

## 4. 3단계: 추진 — 프로펠러까지

- 대형 엔진 실물 카탈로그 (MAN·Wärtsilä 등 공개 스펙, 출처 URL
  필수 — 상상 부품 금지)
- Wageningen B-시리즈 프로펠러 설계: 공개 Kt·Kq 다항식 → 직경(흘수
  제한)·피치비·회전수 최적 → ηD 실산출 → 소요 제동동력 → 엔진 선정
- 캐비테이션 개략 검사 (Keller 기준)
- 검증: B-시리즈 공개 도표(Kt-Kq-J 곡선) 재현 대조

## 5. 4단계: 통합

- 파이프라인 관통: cargo → 상선 치수 → Holtrop → Watson → 프로펠러
  +엔진 → 4중 게이트 → 리포트 (톤급 짐 단위 표기)
- NSGA 탐색 경계 확장 (L 상한)

  상선급 — 스케일 전이가 오히려 자연 대역)
