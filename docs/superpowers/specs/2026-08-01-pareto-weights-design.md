# 파레토 가중 프리셋 + ELO 보정 (#25 2단계)

- 날짜: 2026-08-01
- 상태: 오너 승인 (출처 = 혼합안)

## 1. 목적

파레토 전선은 후보 여러 척 — 최종 선택은 사람 몫이지만, 용도를 알면
**기본 추천 1척**을 자동 표시할 수 있다. 가중 출처는 오너 결정으로
**용도 프리셋 + ELO 취향 보정 혼합**: 원안 6단계의 "사람 피드백 학습"
고리를 추천 체계에 연결.

## 2. 수학

- ELO 대결은 목적 대표선수전 (min_mass/max_stability/min_resistance) —
  세 대표의 ELO 점수를 소프트맥스(T=100, ELO 관례 스케일)로 확률화하면
  취향 가중치가 됨
- 자신감 혼합: **w = (1−α)·프리셋 + α·ELO**, α = min(1, 대결수/10) —
  "데이터 적으면 프리셋, 쌓이면 사람"
- 프리셋 (개략 근거 주석 명시): survey (0.3, 0.2, 0.5·안정 우선) /
  patrol (0.5, 0.2, 0.3·저항 우선) / workboat (0.2, 0.5, 0.3·중량 우선)
  — 순서 (저항, 중량, 안정)
- 추천: 전선 후보의 목적값 min-max 정규화(저항·중량은 낮을수록,
  안정여유는 높을수록 좋게 방향 통일) → 가중합 최대 = ★ 추천

## 3. 구현 자리

- 신규 `src/ai/recommend.py`: `preset_weights`, `elo_weights`,
  `blend`, `recommend(front_df, purpose, elo_csv)` — 손계산 pytest
- `src/optimize.py`: `--purpose` 옵션 → 추천 1척 + 가중 내역 출력
  (투명성), pareto.png에 ★ 강조
- 파이프라인·선별기 무수정 (추천은 출력 계층의 일)

## 4. 한계 (정직)

- 프리셋 수치는 개략 판단 — 실무 근거 없음, ELO가 쌓이며 희석되는 설계
- ELO 대결 현재 2건 → α=0.2. 대결 이력의 목적 대표 이름 규약
  (candidate 이름에 min_mass 등 포함)에 의존
- 다목적 → 단일 점수 축약은 정보 손실 — 전선 전체는 계속 보여주고
  추천은 "기본값" 표시일 뿐
