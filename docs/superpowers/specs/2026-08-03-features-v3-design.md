# 특징 v3 — 평형 정합 + 다충실도 (2026-08-03)

- 상태: 오너 승인 ("추천대로": (a)+(b) 조합)
- 유래: 라벨 10,128장에서 수확 체감 확정 (저항 R² 0.386 정체,
  worklog 08-03) — 데이터 양의 다음 지렛대는 특징의 질.

## 1. 진단 (v2의 약점)

1. 흘수 불일치 잔재: v2 평형 특징은 전 선체 150 kg 고정 개략 —
   라벨은 배마다 다른 무게(120~200 kg)의 평형 흘수에서 채점
2. 조파저항의 눈 부재: 형상 의존 저항은 단면적 종분포가 지배 —
   v2엔 입사각 1개뿐

## 2. 설계

### (b) 평형 흘수 정합 — 소음 제거
- 배마다 라벨 파이프라인과 같은 무게 모델(estimate_weights: 선각
  면적×면밀도×의장 + 짐 100 kg + 추진 고정비율)로 전체 중량 →
  equilibrium_draft 역산
- v2 평형 특징 8종(_eq)을 이 흘수에서 재계산 (개수 불변, 질 상승)
- 정직 한계: 라벨은 설계 나선(모터 선택 반복)까지 돎 — 특징은 고정
  비율 근사. 잔여 불일치 존재 명기

### (a) 다충실도 특징 — 신호 주입
- 신규 2종 (30→32차원):
  - r_michell_lo: 저해상 총저항 (마찰 ITTC + 조파 저해상 Michell,
    1.2 m/s, 평형 흘수)
  - r_wave_lo: 조파 성분 단독 (마찰과 스케일 상이 — 분리 입력)
- 저해상 = michell_wave_resistance_mesh의 n_u/n_x/n_z 축소.
  해상도는 비용 계측 후 확정 — 라벨 계산 대비 1/10 이하 목표
  (특징이 라벨만큼 비싸면 대리모델 존재 이유 소멸)

## 3. 판정관

- 3만 척 특징 재계산 (배경, 발열 로그) → data/shipd/features_v3_loa3.npy
  (v2 파일 보존 — A/B 재현성)
- 같은 10,128 라벨로 재학습 A/B: v2 (분류 0.901 / 저항 R² 0.386 /
  중량 0.730 / 안정 0.525 / 재검증 77%) vs v3
- 주 표적 = 저항 R². 목표 숫자 약속 없음 (에포크 스윕 전례 —
  계측이 판정). 나머지 지표 무회귀 확인

## 4. 검증

- 평형 흘수 손계산 (상자 껍데기: T = m/(ρLB))
- 저해상 vs 정해상 Michell 자릿수 일치 (같은 배 비율 0.5~2 대역)
- 비용 계측 박제 (특징/라벨 비율)
- NaN 규약 유지 (실패 = NaN 행, 조용한 0 금지), 기존 시험 267 무회귀

  후속 후보로 등록 (안정 전용 특징 또는 다중 헤드)
- 분류 소폭 하락 (0.901→0.881)했으나 실전 지표(재검증)는 상승 —
  "작은 검증셋 낙관" 계보의 재확인
