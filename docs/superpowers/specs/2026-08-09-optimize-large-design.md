## 1. 목표

12점 격자 지도를 넘어 **연속 탐색**: 선형(Ship-D 45파라미터)과
속도를 NSGA-II로 동시 최적화 — "규제 여유와 수송 단가의 파레토
전선" + 대표 설계 전체 8중 재검.

## 2. 구조 — `src/ai/optimize_large.py`

- 유전자 46: Ship-D 45 (dataset_bounds·constraints_ok 재사용 —
  shipgen_optimize 계보) + **속도 [5.0, 7.5] m/s**
- 평가 (전부 기존 함수 재사용 — 새 물리 없음):
  1. scaled_mesh(loa 고정 — 임무 8,000t 추정 치수) →
     dims_from_shipd_mesh → design_spiral_large (GM·건현 게이트)
  2. `pipeline._structure_gate` (6번째 — IACS·증육)
  3. `pipeline._economics_gate_large` (8번째 — EEDI EPL·수송단가)
  - 내항·조종 생략 (fast 관례 — 대표 설계만 전체 재검 2단 구도)
- 목적 2: 수송단가 min · attained EEDI(EPL) min. 제약: 나선 합격
  ∧ 구조 합격 ∧ EEDI 합격 (사망 페널티 — 사망 사유 집계 관례)
- 예산 2단: 소예산 (pop 24×gen 12, ~25분) 건강 확인 → **대예산
  (pop 48×gen 25, ~1.5~2시간 배경)** — 전차원 예산 증액 관례
- 산출: outputs/pareto_large_*.csv (커밋 금지) + worklog 전선 표
  + 대표 3척 (최저 단가·최대 규제 여유·무릎점) 중 최저 단가 전체
  8중 재검
