# 쌍동선(카타마란) 개방 — 1단계 기하·정역학·저항 (2026-08-10)

- 상태: 오너 "1번(브레인스토밍) 진행" + 자율 관례 — 쌍동선 선택
  (제품화는 학습 리턴 근거 2회 기각 이력). 폭 통제: **단계 분할**
  — 1단계 = 기하·정역학·저항 관통, 게이트 확장·전 크기는 후속.
- 유래: 실선 수집에 쌍동 1척 (BlueBoat — L/B 1.29, 검증기 쌍동
  대역 LB_RANGE_CAT 1.2 기왕 배선) 보유. 소형 USV 시장의 큰 축.

## 1. 배경 (학부 2학년 눈높이)

- 쌍동선 = 날씬한 반쪽 선체(demihull) 2개를 간격 s로 벌려 연결.
  핵심 물리 = **평행축 정리**: 횡 복원의 원천인 수선면 2차 모멘트가
  I = 2×(I_own + A·(s/2)²) — 간격의 제곱으로 폭증. 날씬한 선체
  (저저항)와 큰 복원(안뒤집힘)을 동시에 얻는 구조
- 대가: 습면적 2배 (마찰 저항↑) + 선체 사이 파 간섭

## 2. 구조 — `src/ai/catamaran.py`

- `generate_catamaran_mesh(dims, separation_ratio=?, ...)` —
  데미헐 = 기존 generate_hull_mesh (날씬 비율 재배분: 데미헐 폭
  = 전폭×비율), y = ±s/2 복제 → trimesh 병합 (단일 수밀 씬)
- 정역학: **기존 evaluate 재사용** — waterplane_properties가
  다중 폴리곤 적분이면 병합 메쉬에서 평행축 효과 자동 (관통 확인
  이 1단계 심장). 실패 시 절단 경로 수리
- 저항: 데미헐 단동 저항 × 2 (메쉬형 Michell 데미헐 1개 평가)
  — **간섭 무시 C급 각주** (Molland 계열 공개 문헌 확보 시 승급
  백로그)

## 3. 앵커

1. **평행축 손계산**: 두 직사각 수선면 (A·s 알려짐) → BM 정확값
   vs evaluate 실측 (1% 대역)
2. 간격 단조: s↑ → GM↑ (물리 방향)
3. **BlueBoat 실선 대조**: L 1.2m·전폭 0.93 (L/B 1.29 실측 계보)
   급 쌍동 생성 → GM·흘수 자릿수 sanity
4. 데미헐 2배 저항 = 단동 평가 2배 항등식

## 4. 관례·리스크

- 간섭 저항 미모델 (C급 각주 — 간격/L 큰 USV 통상 간섭 작음 대역
  문헌 병기 예정), 갑판 연결 구조(크로스 데크) 중량 미모델 (후속)
- 파이프라인 통합·8중 게이트 쌍동 갈래·전 크기는 2단계 이후
- 종결 시 4축 마감
