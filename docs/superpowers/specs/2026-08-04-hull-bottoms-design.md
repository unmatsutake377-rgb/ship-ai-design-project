# 용도별 선저 형상 — Cm 실측 캘리브레이션 (2026-08-04)

- 상태: 오너 승인 (활주 V형 근거 조사 조건부 — 충족)
- 유래: 오너 관찰 "생성 선형에 실제 배의 밑부분이 없다" (ELO 4R
  회전 GIF). 실측: 우리 Wigley 생성기 바닥 폭비율(10% 높이) 0.46 —
  Ship-D 실선형 분포(0.25/0.44/0.68)의 날씬 쪽. 오너 지시: 용도마다
  선저가 다르므로 일괄 아닌 **용도별**, 근거는 웹+Ship-D 통계.

## 1. 근거

- 문헌: 배수량·반배수량 저중속 표준 선저 = round bilge (내항성·계열
  데이터); 하드차인은 활주 영역. 반배수량은 round bilge~차인 경계.
  활주 데드라이즈: Savitsky 방법 자체가 10~30° 실험 회귀, 실선
  트랜섬 10~24° (semi-V 10~17 / deep-V 21~25 / 소형·RC 표준 15°)
- Ship-D 300척 실측 (표본 seed 11): 바닥 폭비율 f10 = 25분위 0.25 /
  중앙 0.44 / 75분위 0.68 → Wigley 지수 역산 Cm = 0.73 / 0.85 / 0.92
