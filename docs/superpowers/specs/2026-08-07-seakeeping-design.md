# 파랑·내항성 — 스트립 이론 정통 (2026-08-07)

- 상태: 오너 승인 (방향 "파랑·내항성", 산출 "둘 다 — 성적표 먼저",
  방법 "스트립 이론 정통", 접근 A 단계 분할 — "진행하고")
- 유래: 원안 6단계 전주 완주 후 첫 심화 캠페인. 현 파이프라인은
  정수(잔잔한 물) 전용 — 파랑 응답은 미개척.

## 1. 구조

신설 `src/physics/seakeeping/` 패키지 — 층별 독립 검증:
- `lewis.py`: 단면 Lewis 등각사상 + 주파수 의존 2D 부가질량·조파감쇠
- `strip.py`: 스트립 적분 → 운동방정식 계수 → 주파수 영역 응답
- `waves.py`: 기진력 (Froude-Krylov + 회절 근사)·ITTC 파랑 스펙트럼
- `criteria.py`: 내항 기준 + 5번째 게이트

## 2. 1단계: Lewis 단면 + 2D 계수

- 단면 (B/T·단면적계수) → Lewis 2-파라미터 사상 → 주파수별
  부가질량 a33(ω)·조파감쇠 b33(ω)
- 검증: **반원 단면 해석해 (Ursell) 대조** + 성질 (감쇠 ≥ 0,
  저주파/고주파 극한) — 표준기 문화
- 메쉬 단면에서 Lewis 파라미터 자동 추출 (기존 절단 인프라 재사용)

## 3. 2단계: heave·pitch RAO (선수파)

- 스트립 적분 → 2자유도 연성 운동방정식 (주파수 영역)
- 기진력: Froude-Krylov + 회절(스트립 근사)
- 검증: **Wigley RAO 문헌 실측 (ITTC 계보)** — 우리 표준기 선형

## 4. 3단계: roll + 불규칙파 성적

- roll: 조파감쇠 미소 → Ikeda 간이 점성 보정 (문헌 계수, 등급 표기)
- 불규칙파: ITTC 스펙트럼(Hs·Tz) × RAO² → 지정 해상 유의 응답
  (heave·pitch·roll·수직가속도)
- 검증: 횡요 고유주기 손계산 + 문헌 대역

## 5. 4단계: 5번째 게이트 + 통합

- 설계 리포트에 내항 성적표: 고유주기·해상 상태별 유의 응답·합불
- 용도별 기준: survey = 계측 가능 한계 계보, cargo = IMO 계보
  (기준값 출처 등급 명시)
- 전 크기 적용 (소형 USV~화물선 — 크기 스위치 없음)
- Gazebo 파랑 세계 = 교차 검증 조각 (러더 관례: 물리 먼저)

## 6. 관례·리스크

- TDD, 해석해·문헌 앵커, 단계 성적표 후 계속/보류, NaN 규약
- 리스크: Lewis 사상의 특이 단면 (극단 B/T·풍만도) 수치 안정성,
  회절 스트립 근사의 단파 한계 — 유효 대역 정직 표기
- 수집 연동: 오너 수집분 (KVLCC2 계열 문헌 등)에서 검증 재료
  보강 가능
