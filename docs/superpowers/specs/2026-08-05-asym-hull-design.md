# 배수량 선형 선수미 비대칭 — 기본 승격 (2026-08-05)

- 상태: 오너 승인 ("바꾼 걸 메인으로" — 시작하자)
- 유래: 오너 관찰 "선수와 선미가 동일 — 실제 배는 다르다".
  Wigley 대칭은 검증용 시험 선형의 잔재 (설계 대상 아님).

## 1. 근거

- 문헌: LCB 위치는 속도 함수 — 저속(Fn 0.2~0.25) full form은 전방
  최대 +3%L, 고속 fine form은 후방 −3%L (Fn 1.0에서 −6%).
  [Aalto L4 Hull form / ScienceDirect Midship Area]
- Ship-D 30,000척 실측 (lcb_frac): LCB 오프셋 중앙 **전방 2.3%L**
  (10~90분위 −11.5%~+5.7%) — 문헌과 정합
- 함의: 저속 배수량선 = 선수 풍만 + 선미 fine(run) — "선수가
  날카롭다"는 통념은 중고속 이미지

## 2. 설계

- 세로 분포를 선수/선미 지수 분리: y ∝ (1−u^n_bow) / (1−u^n_stern)
- (n_bow, n_stern)은 목표 (Cp, LCB 오프셋) 2원 방정식을 수치 역산
  — Cp = ½[n_b/(n_b+1)+n_s/(n_s+1)], LCB는 모멘트 적분 해석식
- 용도 프리셋 LCB_BY_PURPOSE: survey −0.02L(전방 2%), workboat
  −0.025L (Ship-D 중앙 부근). patrol·활주는 기존 비대칭 계열 무수정
- **기본 승격**: 파이프라인 배수량 경로 기본 = 비대칭. 저수준
  generate_hull_mesh(asym 미지정) = 대칭 유지 — Michell 해석해
  대조·CFD 캘리브레이션의 표준기 보존 (검증 채널)

## 3. 연쇄 갱신

- 중량: 구조 LCG = 0(대칭 가정) → 메쉬 부피 도심 근사 (명명 개략)
- 트림: LCB≠0 — 리포트에 LCB·정적 트림각(소각 선형, 다구획 3단계
  도구 재사용) 표기, 경고 기준을 |LCG−LCB| 기반으로
- 문지기 라벨·파레토 재생성 (신세계 3판)

## 4. 검증

- 손계산: 대칭 극한(n_b=n_s) = 기존과 동일 (무회귀), LCB 목표
  ±0.3%L 달성 (메쉬 적분 대조), Cb 유지, watertight
- Ship-D 대역: 생성 LCB가 실측 10~90분위 안
- 기존 시험 무회귀 (Michell 해석해 시험 = 대칭 채널)

## 5. 정직 한계

- 비대칭은 세로 분포만 — 단면 모양(cm)은 전 길이 공유, 실선의
  선미 트랜섬(배수량형)은 미도입 (후속)
- 구조 LCG 도심 근사는 껍데기 실분포 아님
- Michell 저항은 비대칭 메쉬 경로(수치)로 계산 — 해석해 교차는
  대칭 채널에서만
