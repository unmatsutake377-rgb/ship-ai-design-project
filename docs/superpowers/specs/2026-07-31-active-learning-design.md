# 능동 학습 사이클 1회전 설계 — CFD 라벨로 Michell 보정 계수 학습

- 날짜: 2026-07-31
- 상태: 오너 승인 (학습 대상·표본 전략·접근 A 모두 대화로 확정)
- 위치: 원안 Step 5의 후반부 — CFD 훅(전반부, 완결)이 만든 라벨을
  실제로 "학습"에 사용하는 첫 사이클

## 1. 목적과 범위

**목적**: CFD 정밀 라벨 소수(K척)로 경험식의 계통 오차를 보정하고,
보정된 경험식으로 파레토 후보를 재평가해 "정밀 해석이 설계 선택을
바꾸는가"를 관찰한다 — 능동 학습 루프의 1회전.

**학습 대상 결정 (오너)**: 대리모델 재학습이 아니라 **경험식 보정
계수**. 근거: 3만 표본에 CFD 몇 행을 섞는 재학습은 통계적으로 무의미
(바닷물에 잉크 한 방울) — 적은 표본으로도 의미 있는 것은 "Michell이
통통한 배에서 얼마나 과대예측하나"라는 구조적 비율.

**표본 전략 (오너)**: 파레토 상위가 아니라 **L/B 스팬** — 보정 계수의
설명변수(날씬함) 축을 넓게 커버해야 곡선을 배울 수 있음. 3척인 이유:
매개변수 1개 적합에 4점(기존 1+신규 3)이면 검증 여유 2점, 척당 ~1시간,
그리고 "배운 뒤 다음 표본을 고른다"는 능동 학습 원리상 1회전 최소 구성.

## 2. 아키텍처

```
[표본] src/cfd/samples.py — Wigley 3척 산출물 폴더 생성 (hull.stl+report.json)
   ↓
[CFD] 기존 훅 재사용 (hook.py + run_case.sh) — 척당 단상+자유수면
   ↓ data/cfd_labels.csv 6행 추가 (총 8행)
[학습] src/cfd/calibration.py — ratio_w(B/L) 적합
   ↓
[재평가] 파레토 24척 rw × 보정 → 순위·전선 변화 리포트 + 그림
```

새 코드는 samples.py·calibration.py 2개 모듈뿐 — CFD 실행 경로는 훅
그대로 (YAGNI). 거부한 대안: B) 전체저항 통짜 보정 (마찰·조파 뒤섞여
물리 해석 오염), C) 베이지안 능동 선택 (표본 4개에 과잉 — 후속 확장).

## 3. 표본 3척 (변인 통제)

| | L/B=4 | L/B=7 | L/B=10 |
|---|---|---|---|
| L×B [m] | 3.0×0.75 | 3.0×0.43 | 3.0×0.30 |

- 공통: **Fn=0.341 고정** (v=1.85 m/s), Cb=0.444 (표준 Wigley n=m=2),
  B/T=1.6 (표준 비율), 흘수 T=B/1.6
- Fn을 고정하고 L/B만 움직이는 이유: Michell 오차는 둘 다에 의존 —
  한 번에 한 변수만 (Phase B 격리 실험 원칙)
- 기존 라벨(L/B=2.0 데모선, 같은 Fn 0.341)과 합쳐 4점: B/L = 0.50,
  0.25, 0.143, 0.10

## 4. 보정 수학

ratio_w = CFD 조파 추정 / Michell 조파,
CFD 조파 추정 = P_자유수면 − P_이중모형 (같은 척 두 모드 실행의 이유)

적합 모형: **ratio_w(B/L) = 1 + b·(B/L)**, 매개변수 b 하나.
- 물리 앵커: B/L→0 (무한히 얇은 배)에서 Michell 정확 → ratio=1 고정.
  절편을 데이터가 아니라 물리가 정함 — 소표본에서 튼튼
- 최소제곱: b = Σ[(ratio_i−1)·x_i] / Σ[x_i²], x=B/L
- 안전 클리핑: 적용 시 ratio ∈ [0.05, 1.5] (외삽 폭주 방지)
- 적용: rw_보정 = rw_Michell × ratio_w(B/L). **마찰(ITTC-57)은 무보정**
  — 거친 격자 CFD 마찰(과소예측)로 100년 검증식을 고치지 않는다

## 5. 재평가

기존 Wigley 파레토(outputs/pareto/pareto.csv, 24척) 각 후보의 rw에
보정 적용 → 전저항 재계산 → 파레토 전선 재판정 → 산출물:
- 순위 변동 표 (전선 진입/탈락 배 목록)
- 보정 전/후 전선 겹쳐 그린 그림
- 주의 표기: 파레토는 Fn 0.19~0.27 — 보정 유효역(Fn≈0.34) 밖의
  **외삽 시연**임을 리포트에 명시

## 6. 검증 (pytest — CFD 불필요)

- 합성 4점 → b 손계산 일치 / 앵커 ratio(0)=1 / 클리핑 경계
- 재평가: 마찰 성분 불변 단정, 보정 후 전저항 = rf + rw×ratio 폐합
- CFD 라벨 수확은 기존 훅 시험이 커버

## 7. 알려진 한계 (정직 목록)

1. **Fn≈0.34 근방만 유효** — Fn 의존성 미학습. 재평가는 외삽 시연
2. 거친 격자 CFD는 조파 과소예측 경향 → 보정이 과하게 깎을 수 있음
   (진짜 비율은 추정보다 위). 격자 수렴 연구가 선행돼야 정량 신뢰
3. Wigley 계열만 — 트랜섬·활주 미적용
4. n=4 — 직선 이상 형태 판별 불가. 다음 회전에서 불확실 최대 지점에
   표본 추가 (그것이 능동 학습의 본래 루프)
