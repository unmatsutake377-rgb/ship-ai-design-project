# CII 운항 탄소등급 — 경제성 캠페인 확장 (2026-08-09)

- 상태: 오너 "물어보는 것 제외하고 계속 진행" 위임 — 자율 설계.
  선정 근거: EEDI의 자매 규제 (같은 원전 계보·연료 사슬 재사용 —
  리턴 확실성 최상), EEXI는 현존선 개조용이라 신조 설계 파이프라인
  비대상 (정직 스킵 박제)
- 유래: 경제성 캠페인 (8번째 게이트) 완주 직후 확장 — EEDI는
  "설계 연비 규제", CII는 **"운항하면 매년 받는 탄소 성적 A~E
  등급"** (2023 발효 현행 제도)

## 1. 배경 (학부 2학년 눈높이)

- **CII** (Carbon Intensity Indicator) = 실제 운항 1년의 CO₂ ÷
  (DWT × 운항 거리) [gCO₂/(DWT·nm)] — attained AER
- required CII = 2019 기준선(a·DWT^−c) × (1−Z%) — Z가 매년 강화
  (2023 5% → 2026 11%)
- 등급: attained/required 비를 선종별 경계 4개와 비교 → **A(우수)
  ~E(퇴출 위기)** — D 3년 연속·E 1년이면 시정계획 의무
- 우리 사슬: opex 연간 연료 → CO₂ → AER → 등급 + **연도별 전망**
  (몇 년에 등급이 떨어지나)

## 2. 구조

- `src/physics/economics/cii.py`:
  - `attained_aer(fuel_t_per_year, dwt_t, distance_nm_per_year, cf)`
  - `required_cii(dwt_t, year)` — 기준선 × (1−Z)
  - `cii_rating(attained, required)` — A~E (경계 비교)
  - `cii_outlook(...)` — 2023~2026 확정 + 2027+ 미정 표기
- economics 리포트 통합: 대형 EEDI 항목에 `cii` 병기 (**게이트
  아님** — 운항 지표는 성적표, E등급 시 note 경고. 8중 유지)
