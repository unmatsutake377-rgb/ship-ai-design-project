# 구조 강도 — 6번째 게이트 "부러지나" (2026-08-09)

- 상태: 오너 승인 (방향 "구조 강도", 범위 "종강도 + 국부 판 두께
  + 간이 보강재 배치", 파랑 하중 "IACS 정본 + 스트립 교차검증",
  재료 "강 + 알루미늄 + FRP 3종", 진행 구조 "A. 하중 먼저")
- 유래: 원안 6단계 + 내항성 심화 완주 후 두 번째 심화 캠페인.
  현 파이프라인은 배를 강체로 가정 — 선체가 부러지는지(종강도)와
  판이 수압을 버티는지(국부 강도)는 미개척.
- 규모 경고: 내항성급 이상 (3~4회차 예상) — 단계 분할·성적표
  관례로 통제.

## 1. 물리 배경 (학부 2학년 눈높이)

배는 거대한 보(beam). 중량 분포(기관실·화물 몰림)와 부력 분포
(선체 형상)가 길이 방향으로 어긋나면 배가 휜다:
- **정수 굽힘**: 잔잔한 물에서도 분포 차이만큼 휨
- **파랑 굽힘**: 파정에 올라타면 호깅(가운데 볼록), 파곡에
  걸치면 새깅(가운데 오목)
- **국부 강도**: 판 하나하나가 국부 수압·갑판 하중을 버티는지
- 판정: 굽힘 응력 σ = M/Z ≤ 허용 응력 (Z = 단면계수 — 단면이
  휨에 저항하는 능력, 중립축에서 먼 갑판·킬이 먼저 아픔)

## 2. 구조 — 신설 `src/physics/structure/` 패키지

층별 독립 검증 (내항성 seakeeping/ 관례):

| 모듈 | 역할 |
|---|---|
| `loads.py` | 중량−부력 길이 분포 → 전단력 V(x)·굽힘 모멘트 M(x) 정수 곡선. 부력 = 기존 메쉬 절단(스테이션 단면적) 재사용, 중량 = 성분별(구조·기관·화물·연료) 길이 배치 모델 |
| `wave_loads.py` | IACS UR S11 파랑 굽힘 (호깅/새깅, 파랑계수 Cw) 정본 + 스트립 이론 하중 적분 교차검증 |
| `materials.py` | 재료 3종 물성 — 연강(σy 235 MPa)·고장력강 AH36(355)·알루 5083 **용접부 강도**(용접 열영향부 항복 저하 — 함정 지점, 원전 수치)·FRP 적층(ISO 12215 물성식 계보). 용도·길이 자동 선택 + 사용자 재지정 |
| `scantlings.py` | 국부 설계 압력 → 판 두께 규칙식 (소형 ISO 12215-5 계보 / 대형 선급 계보) → 종늑골 간격·보강재 간이 배치 (판+부착 플랜지 단면 모듈러스) |
| `midship.py` | 상자보(갑판·선측·선저 판) + 보강재 단면 조립 → 중립축·단면 2차 모멘트 → 단면계수 (갑판·킬 2곳) |
| `strength.py` | 판정 σ=M/Z vs 허용 응력, 부족 시 두께 증가 수렴 루프, 구조 중량 실측 재계산 |

데이터 흐름: 메쉬+중량 → 하중 곡선 → (+IACS 파랑) 총 모멘트 →
요구 단면계수 → 규칙 두께 단면 조립 → 실제 단면계수 → 판정·수렴
→ 6번째 게이트.

## 3. 원전·검증 앵커 (기억 하드코딩 금지 관례)

- 원전 확보 순서: IACS UR S11(공개 PDF, iacs.org.uk) → DNV 규칙
  (공개 다운로드) → ISO 12215-5(유료 가능성 — 확보 실패 시 공개
  교재·논문 대체 정직 기록, SEAWAY 대체 관례)
- 앵커 사다리:
  1. 하중 폐합 항등식 — V·M 양끝 0, ∫(중량−부력)dx=0 (전 선형
     상시 자기검증)
  2. 상자 바지선 + 편중 화물 해석해 (손계산 정답 — 반원 Ursell 격
     표준기)
  3. IACS 공식값 재현 (문서 수치 예제)
  4. 단면계수 손계산 (단순 상자 + 보강재 1개)
  5. 실선 sanity 대역 — 100m급 외판 10~15mm, 소형 알루 4~6mm
     (문헌 대역 정직 표기)

### §3 보강 — IACS UR S11 구현 인덱스 (2026-08-09 확보)

- 확보: turkloydu.org 선급 미러 `UR_S11_Rev9_TR_EN.pdf` (Rev.9
  2019, 2020-07 발효) → `references/IACS_UR_S11.pdf` (gitignore).
  iacs.org.uk 목록 페이지는 JS 렌더라 직링크 불가 — 미러 경로 기록.
- 구현 인덱스 (PDF 페이지, 0-기준):
  - p0 S11.1: 적용 범위 — **강선 L ≥ 90 m** (소형·비강선 정직 거절
    근거)
  - p3 S11.2.2.1: 파랑 굽힘 Mw — 호깅 +190·M·C·L²·B·Cb·10⁻³,
    새깅 −110·M·C·L²·B·(Cb+0.7)·10⁻³ [kN·m], M = 분포계수
    (미드십 1.0, Fig.2), **Cb 하한 0.6 클램프 원전 명시**
  - p3: 파랑계수 C — 10.75−((300−L)/100)^1.5 (90≤L≤300) /
    10.75 (300~350) / 10.75−((L−350)/150)^1.5 (350~500)
  - p3~4 S11.2.2.2: 파랑 전단력 Fw (분포계수 F1·F2 Fig.3~4)
  - p5 S11.3: **허용 굽힘 응력 σ = 175/k N/mm²** (k=1 연강,
    고장력강 k<1은 UR S4) — 3단계 판정 재료
  - p7~ S11.5: 좌굴 검사 (판·종늑골) — 2단계 이후 재료
- 계획 예상 상수와 원전 완전 일치 — 수정 불요.

## 4. 파이프라인 통합·되먹임

- `run_pipeline` 6번째 게이트:
  `passed = hydro ∧ space ∧ seakeeping ∧ structure`
  (기존 시험은 `structure=False` 명시 — 내항성 플래그 관례 재사용)
- **중량 이중 계산 방지**: 대형 경하 정본 = Watson 유지. 구조 실측
  중량은 성적표에 교차 검증 수치로 병기 (Watson vs 실측 비율 —
  안정되면 승급 검토). 소형은 기존 구조 중량 모델과 비교 병기.
- 성적표 항목: 정수/호깅/새깅 모멘트, 요구/실제 단면계수, 지배
  위치(갑판 vs 킬), 판 두께 표, 재료, 수렴 반복 수

## 5. 단계 분할 (A. 하중 먼저 — 각 단계 성적표 후 계속/보류)

1. **하중**: loads + IACS 파랑 + 스트립 교차검증 (바지선 앵커)
2. **단면**: materials + scantlings + midship (손계산 앵커)
3. **판정·통합**: strength 수렴 루프 + 6번째 게이트 + 4축 마감
