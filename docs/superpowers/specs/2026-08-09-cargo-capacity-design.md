# 대형 화물창 용적 게이트 (2026-08-09~10)

- 상태: 오너 직접 지시 ("대형 화물창 용적 게이트 진행하자") +
  자율 관례 유지 (질문 생략). NSGA 캠페인의 정직 각주가 낳은
  최우선 백로그 — 날씬 전선(Cb 0.29~0.44)이 8,000t를 실제로 실을
  수 있는지 미검이었음.
- 위치: 8중 게이트의 **space 축이 대형 분기에 비어 있던 구멍을
  메움** (소형은 MaxBox 기존) — 게이트 수 불변.

## 1. 배경 (학부 2학년 눈높이)

- 짐 8,000t은 무게이자 **부피**: 일반화물 적재계수(stowage factor)
  1.3 m³/t (실선 1.2~1.5 대역 C급 — 초안의 소형 밀도 500 재사용은
  과대 요구 오판, 구현 중 정정) → 요구 용적 10,400 m³
- 배의 화물창 용적 = 선체 내부 전체 − (이중저 + 기관실 + 연료 탱크
  + 구조 부재) — 날씬한 배는 같은 길이여도 내부가 훨씬 작다

## 2. 구조 — `src/physics/cargo_capacity.py`

- `hold_volume_large(mesh, depth, loa, fuel_t) -> dict`:
  - 전체 내부: 메쉬를 z=depth까지 절단한 부피 실측 (기존
    immersed_volume 계보 재사용 — "흘수" 자리에 depth)
  - 공제 ① 이중저: z < h_db 부피 실측 절단, h_db = B/15
    (0.76~2.0 m 클램프 — SOLAS II-1 계보, 원문 유료라 C급 정직)
  - 공제 ② 기관실: 선미 15% 구간 부피 실측 절단 (중량 블록
    machinery 배치 0.10~0.30과 정합 계보)
  - 공제 ③ 연료 탱크: fuel_t / 0.9 t/m³
  - 구조 부재·통로 공제: ×0.90 (grain capacity 관례 C급)
- 게이트: `space_ok = hold_m3 ≥ payload_t × 1.3` (적재계수) —
  대형 분기 passed 합성 + fast 평가(evaluate_large_vector)에도
  삽입 (절단 2회 — 저렴)

## 3. 앵커

1. 상자 바지선 손계산 (부피 = L·B·D 정확, 공제 산식 검산)
2. 표준 화물선 (Cb 0.75, 8,000t) 합격 — 기존 설계 생존 확인
3. **NSGA 진짜 전선 3척 재판정** — 날씬 선형의 운명 실측 (이
   게이트의 존재 이유)
4. NSGA 스모크 재실행 (게이트 추가 후 사망 집계에 space 반영)

## 4. 리스크·관례

- 공제율·밀도 = C급 관례 (수집 후보: 실선 grain capacity)
- 전선 재판정 결과가 전멸이어도 정직 기록 (게이트가 일하는 증거)
- 종결 시 4축 마감
