**Goal:** 목적(적재·속도·항속) 입력 → Wigley 파라미터 공간을 NSGA-II로 탐색 → 저항·중량·안정여유의 **파레토 전선** + 후보 목록 산출 (스펙 §7, 오너 결정 1·3).

**Architecture:** `src/optimize.py` 신설. 평가 함수 = 기존 파이프라인 재사용 (설계 나선을 `design_spiral()`로 추출해 공유). 설계 변수 4개: [L, L/B, B/T, Cb]. 물리 직접 평가 (대리모델 가속은 M5b-1 이후 2차). 라이브러리: pymoo (산업 표준 NSGA-II 구현).

**목적함수 (오너 결정 1 — 파레토):**
- f1 = 전저항 @ 목표속도 [N] (최소화)
- f2 = 전체 중량 [kg] (최소화 — 비용 대리값)
- f3 = −안정여유 (최소화) — 여유 = min(GM/B − 0.04, 0.40 − GM/B): 밴드 중앙일수록 큼

**제약:** Fn < 0.4 (배수량형), 필터 3종(배수량·GM밴드·건현) 통과, Cb 도달범위.
위반/예외(침수 등) = 사망 페널티 (F=큰값, 후보 자연 도태).

**설계 변수 범위:** L ∈ [1.2, 6.0] m, L/B ∈ [1.7, 4.0] (실선 통계 주변), B/T ∈ [2.5, 6.0], Cb ∈ [0.35, 0.60] (생성기 범위 안).
