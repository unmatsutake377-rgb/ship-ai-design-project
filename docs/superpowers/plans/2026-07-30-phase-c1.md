# Phase C-1 구현 계획 — 반배수량 개방 (트랜섬 선형 + 저항 + 게이트)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 체크박스 구문.

**Goal:** 실선 USV의 주 운항 속도대(Fn 0.4~1.0, 반배수량)를 파이프라인에 개방 — 지금까지 "미지원 거절"하던 요청(예: 4m급 5 m/s 순찰정)이 설계 가능해짐.

**3요소:**
1. **트랜섬 선형 생성기** — Wigley류 선수부 + 평행부 + 트랜섬 선미 파라메트릭 (spec v2 §2.2 예고). 반폭 y=(B/2)·F(x)·H(z), F는 선수/선미 비대칭 (선미는 트랜섬 폭비 β_t로 절단), 트랜섬면·갑판 캡으로 watertight. Cb↔지수 역산 유지 (β_t 고정 파라미터).
2. **반배수량 저항** — ITTC-57 마찰 + **메쉬 Michell** (이중검증 자산 재사용 — Fn 0.4~1.0에서 근사 유효, 한계 명시) + **트랜섬 저항항** (환기 트랜섬 기저 저항 — 명명 상수, 개략임을 표시). Holtrop 금지 원칙 유지.
3. **체계 게이트 개방** — `require_supported`가 SEMI_DISPLACEMENT 허용 (활주만 거절 유지), 속도 범위 함수 확장 (semi 상한 Fn≈1.0), 파이프라인 분기: 반배수량이면 트랜섬 생성기 + 메쉬 저항 경로.

**검증 (정직 원칙 — 정량 문헌 벤치마크 부재 명시):**
- 트랜섬 메쉬: watertight + 부피 적분 폐합 (해석 Cp·Cm 관계)
- 저항: (a) Fn 0.2~0.9 저항곡선 연속·단조성 (b) **교차 검증: 저속(Fn 0.25)에선 Wigley가, 고속(Fn 0.6)에선 트랜섬선이 유리해지는 역전 확인** — 물리적으로 예상되는 질적 패턴
- 게이트: 기존 거절 케이스(5 m/s 순찰)가 이제 설계 통과

**한계 명시:** 반배수량 동적 부상(트림 변화·침수면 감소) 미모델 — 정적 흘수 기반 근사. 활주(Savitsky)는 다음 단계.

## Task 1: 트랜섬 선형 생성기 (`hull_generator.py` 확장)
- `generate_transom_hull_mesh(dims, transom_ratio=0.6, n_stations, ...)` + `solve_transom_exponents(cb, ...)`
- 테스트: watertight, 부피 폐합 (2%), 트랜섬 면 존재 (x=−L/2 평면 정점들 y 폭 = β_t·B/2 근사)

## Task 2: 저항 확장 (`resistance.py`)
- `transom_drag(speed, transom_area, rho)` — 기저저항 계수 상수
- `total_resistance_semi(mesh, loa, draft, speed, transom_area)` = ITTC + 메쉬 Michell + 트랜섬항
- 테스트: 저항곡선 연속·단조, Wigley↔트랜섬 교차(역전) 확인

## Task 3: 게이트 개방 + 파이프라인 분기
- regime: SEMI 허용, `max_semi_speed(loa)` = 1.0·√(gL)
- pipeline: 체계별 생성기·저항 경로 분기, 리포트에 체계·트랜섬 정보
- 테스트: 5 m/s 순찰 케이스 통과 (기존 거절 테스트는 활주 케이스로 상향)
