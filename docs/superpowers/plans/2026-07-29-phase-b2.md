# Phase B-2 구현 계획 — Gazebo 스폰 + 부력 교차 검증

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 체크박스 구문.

**Goal:** 우리 설계를 Gazebo(gz sim) 컨테이너의 물에 띄우고, **Gazebo 부력 물리가 계산한 정착 흘수가 우리 정역학의 평형 흘수와 일치**하는지 교차 검증 — 단순 "스폰 성공"이 아니라 두 독립 물리의 합치가 합격 기준.

**단계:**
- **B-2a: 시뮬 이미지** — `ros2_ws/docker/Dockerfile`: FROM ros:jazzy + ros-jazzy-ros-gz (Gazebo Harmonic, arm64). 빌드 후 `gz sim --versions` 스모크. 이미지는 로컬 빌드 (레지스트리 푸시 없음).
- **B-2b: SDF 내보내기** — `ros2_export`에 `export_sdf(report, mesh_path, out_dir)` 추가: model.sdf (질량·관성·메쉬 visual/collision) + 부력 월드 world.sdf (Buoyancy 플러그인, 유체밀도 1025, 수면 z=0 — 모델은 흘수 예측치만큼 잠기게 초기 배치). 주의: Gazebo Buoyancy의 메쉬 collision 부피 처리 방식이 근사일 수 있음 — 결과 해석 시 감안, 필요 시 허용오차 완화 근거로 기록.
- **B-2c: 부양 실험** — 컨테이너에서 헤드리스 실행 (`gz sim -s -r`), 모델 pose 토픽 수 초 기록 → 정착 z에서 흘수 환산 → 우리 equilibrium_draft와 비교 (1차 허용오차 ±20% — 메쉬 collision 근사 감안, 실측 후 조정).

**테스트:** export_sdf XML 유효성·질량 일치 (도커 불필요). 도커 의존 검증은 CLI 스크립트 + 결과 기록 (CI 아님).
