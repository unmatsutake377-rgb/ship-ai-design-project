# Phase B-1 구현 계획 — ROS2 컨테이너 + 내보내기 어댑터

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 체크박스 구문.

**Goal:** ① Mac Docker에서 ROS2 기동 확인 ② 우리 설계(report.json)를 ROS2 세계로 번역하는 어댑터 — URDF(기하·관성) + 유체계수 YAML(spec §2.4: "URDF만으로는 유체역학이 전이되지 않음 — 어댑터의 본질은 계수 변환기").

**단계 분해 (오늘 = B1):**
- B1a: ROS2 공식 이미지(ros:jazzy, arm64 네이티브) 스모크 — talker/listener 노드 통신
- B1b: `src/sim_adapters/ros2_export.py` — 순수 Python (도커 불필요, TDD):
  - `export_urdf(report, mesh_path, out_dir)` → `<선체>.urdf`: 메쉬 지오메트리 + 질량 + 관성 (Izz는 M4a 분포모델, Ixx·Iyy는 회전반경 개략)
  - `export_hydro_yaml(report, out_dir)` → 부가질량(Xu̇·Yv̇·Nṙ)·감쇠(Xu·Yv·Nr·Nv)·추력기 배치 — Gazebo 유체 플러그인 파라미터 형식
  - CLI: `python -m src.sim_adapters.ros2_export --report outputs/demo/report.json --out ros2_ws/export`
- B1c: 컨테이너 안에서 URDF 유효성 검사 (`check_urdf`) — 우리 산출물이 ROS2 도구를 통과하는지
- B2 (다음 세션): Gazebo(gz sim) 기동 + 모델 스폰 + 유체 플러그인 연결

**테스트:** URDF XML 스키마 파싱(내장 xml), 질량·관성 값 일치, YAML 라운드트립, 계수 부호 규약 문서화. 도커 의존 테스트는 skipif(docker 없음).
