# Phase C-2 구현 계획 — 활주형 (Savitsky)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 체크박스 구문.

**Goal:** 활주 체계 개방 — 원안 프롬프트의 전 속도 영역 완성. 파이프라인이 고속 보트(Fn∇≥3 또는 Fn≥1)를 Savitsky 평형으로 설계.

**물리 (Savitsky 1964 — 프리즘 활주정 반경험식):**
- 속도계수 Cv = V/√(g·b), 요구 양력계수 C_Lβ = Δ/(½ρV²b²)
- 데드라이즈 보정: C_Lβ = C_L0 − 0.0065·β·C_L0^0.60 (β[deg]) → C_L0 역산
- 양력식: C_L0 = τ^1.1·(0.0120·λ^0.5 + 0.0055·λ^2.5/Cv²) → (τ, λ) 관계
- 압력중심: Cp = lcp/(λ·b) = 0.75 − 1/(5.21·Cv²/λ² + 2.39) → LCG와 모멘트 균형
- 이중 이분법: τ 바깥 루프 (모멘트 잔차), λ 안쪽 루프 (양력 일치)
- 저항: R = Δ·tanτ + Df/cosτ, Df = ½ρV₁²·(λb²/cosβ)·Cf(ITTC), V₁ = 바닥 평균유속 (Savitsky 근사)

**검증 (원논문 워크드 예제 정량표 미확보 — 접근 시 추가 예정 명시):**
① 경험식 전사: 손계산 고정값 대조 (τ=4°, λ=2, Cv=3 등)
② 평형 자기일관: 풀린 (τ,λ)에서 양력=무게 1e-3, 압력중심=LCG 1e-3
③ 물리 경향: Δ↑→τ↑ / V↑→λ↓ / β↑→τ↑ (동일 조건)

**통합:**
- 활주 선체: 프리즘 데드라이즈(V바닥, β=15° 상수) + 하드 차인 + 트랜섬 — 공용 빌더 재사용 (정지 정역학·GM은 기존 필터 그대로)
- design_spiral: resistance_fn에 weights 전달 확장 (Savitsky는 질량·LCG 의존 — 나선과 자연 결합)
- regime: PLANING 게이트 개방 (전 체계 지원 도달), 리포트에 주행 트림·침수길이·활주 여부
- 예상 정직 이슈: 활주 소요 추력이 카탈로그(T500×2=316N) 초과 시 NoSuitableMotor 거절 — 카탈로그 확장 필요 메시지 그대로 노출
