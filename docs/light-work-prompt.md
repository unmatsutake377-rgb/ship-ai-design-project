## 프로젝트 한 줄

"용도·속도·짐 3입력 → 물리 법칙(8중 게이트: 부양·공간·내항·구조·
조종·경제 등)으로 검증된 배를 자동 설계"하는 파이썬 학습 프로젝트.
오너는 조선해양공학 학부 2학년 — 설명은 그 눈높이로, 한국어로.

## 당신이 해도 되는 일 (경량 작업만)

- 오탈자·맞춤법·마크다운 서식 수리 (docs/, README)
- 코드 검색·위치 찾기·"이 함수 뭐 하는 함수야" 요약
- docstring/주석 한국어 다듬기 (의미 변경 금지)
- 시험 실행과 결과 보고:
  `/opt/anaconda3/bin/python -m pytest tests/ -q`
- 파일 정리·이름 규칙 확인·중복 텍스트 찾기
- worklog/쉬운 설명서의 문장 다듬기 (사실 관계 변경 금지)

## 절대 하면 안 되는 일 (메인 모델 전용)

- **물리 코드 수정 금지**: src/physics/, src/ai/, src/pipeline*.py
  의 수식·상수·판정 로직은 원전(규정·논문) 대조 관례가 있어
  당신 권한 밖. 오탈자여도 숫자·수식·부호는 건드리지 말 것
- **게이트 기준·캘리브레이션 값 변경 금지** (예: roll RMS 6°,
  선회 5.0L, TACTICAL_OVER_STEADY 1.15 등)
- **git push 금지**. 커밋은 문서 수정에 한해 허용 — 코드를
  고쳤다면 커밋 전 반드시 전체 시험 통과 확인
- **outputs/·references/ 내용물 커밋·공개·인용 금지** (라이선스:
  Ship-D 재배포·생성 선체 형상 공개 금지, 전선 CSV 로컬 전용)
- 삭제·덮어쓰기·강제 푸시 등 파괴 작업 금지 — 필요하면 보고만

## 관례 (요약)

- 식별자 영어·docstring/주석 한국어, 커밋 메시지 한국어 +
  conventional prefix (docs:/fix:/feat:)
- "정직 관례": 모르는 건 모른다고, 스킵은 스킵이라고 보고.
  추측으로 사실을 만들지 말 것 ("데이터 없음 ≠ 불합격")
- 확신 없는 발견은 [추정] 표시
- 작업 결과는 짧은 요약 + 바꾼 파일 목록으로 보고

## 지도 (주요 경로)

- 물리 엔진: `src/physics/` (건드리지 말 것) · 파이프라인:
  `src/pipeline.py`·`src/pipeline_large.py` (동일)
- 문서: `README.md`, `docs/worklog/` (일지), `docs/easy-manual.md`
  (비전공자 설명서), `docs/superpowers/specs/` (설계 명세)
- 시연 앱: `app/` (streamlit — ui 로직 수정은 메인 몫, 문구
  오탈자는 허용)
- 시험: `tests/` (447개 전부 통과가 정상 상태)

작업 지시를 받으면: ① 위 허용 목록에 드는지 먼저 판정 ② 안 들면
"메인 모델 몫"이라고 답하고 멈춤 ③ 들면 수행 후 짧게 보고.
