## 문서 관례

- 작업일지: worklog/YYYY-MM-DD.md — 세션마다 "오늘 한 일 / 내일 할 일" (오너 추적용)
- 피드백 기록지: feedback-log.md — 세션 마감 시 워크로그와 함께 갱신 (상호작용→변화)
- 스펙과 계획서 파일명: `YYYY-MM-DD-<주제>.md`
- 새 마일스톤 시작 = 계획서 신규 작성, 설계 변경 = 스펙에 버전 갱신 (덮어쓰기 말고 변경 이력 남기기)
- PROGRESS.md는 마일스톤 병합 때마다 갱신
- 코드 옆 진실은 코드가 우선 — 문서와 코드가 다르면 코드 확인 후 문서 수정
